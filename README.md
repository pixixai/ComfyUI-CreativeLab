# ComfyUI-CreativeLab (CLab)

CLab (Creative Lab) 是一个为 ComfyUI 打造的任务管理面板。通过任务卡片、参数表和 XY 矩阵，可以在保留工作流连线的情况下，管理任务、批量设置参数和运行参数组合。

---

## 💡 如何打开插件？

- **快捷键**：按下键盘上的 `C` 键（可在设置中自定义）。
- **界面入口**：点击 ComfyUI 顶部主菜单栏右侧的 **CLab** 图标按钮。

    ![alt text](images/meun_tool.png)

---
## 🗂️ 工作区

顶部标签栏用于切换工作区。每个工作区独立管理任务、参数值、节点绑定和生成历史。复制工作区后，可以在副本中绑定另一组节点。

常用操作：

1. **新建**。点击标签栏末尾的 `+` 新建工作区。
2. **重命名**：双击标签文字可直接重命名。
3. **右键菜单**：支持新建、复制、重命名、删除。
4. **多选**：`Ctrl/Cmd` 点选多标签，`Shift` 区间多选。
5. **拖拽排序**：支持拖拽重排标签顺序（多选后也可批量移动）。

保存与恢复：

- 首次修改插件数据时自动创建配置锚点。按 `Ctrl+S` 将工作区保存到工作流，重新打开时自动恢复。
- 打开旧工作流时，每个旧通道转换为一个独立工作区，带入该通道的绑定及原任务、参数值和历史。单通道工作区保留原名。

## 📐 工作区模式

点击当前工作区名称旁的模式文字，可选择「任务卡片、参数表、XY 矩阵」。其他工作区悬停时显示小三角。默认名称带模式前缀，如「参数表·工作区 1」，手动重命名后使用自定义名称。首次进入参数表或 XY 矩阵后，工作区会保留该结构类型；可往返任务卡片查看、编辑原任务，参数表与 XY 矩阵之间禁止直接或经任务卡片中转互换，不兼容选项置灰。每个工作区分别保存模式、模板、坐标轴及画布视角，返回原模式后无需重新绑定 X/Y/Z 轴。

### 任务卡片

每张卡片独立组织输入、输出和生成历史，适合混合不同结构的任务。阅读[任务卡片说明](web/docs/任务卡片.md)。

![任务卡片模式](images/workspace-cards.png)

### 参数表

每行一个任务，每列一个输入或输出模块。适合统一设置列绑定、批量取值，或从 Excel 粘贴数据。阅读[参数表说明](web/docs/参数表.md)。

![参数表模式](images/workspace-table.png)

### XY 矩阵

在画布上设置 X、Y 轴的参数组合，通过可选的 Z 轴分层，按格子运行并比较生成结果。阅读[XY 矩阵说明](web/docs/XY矩阵.md)。

![XY 矩阵模式](images/workspace-xy.png)

## 📥 导入

https://github.com/user-attachments/assets/12f6ba64-4524-4fd9-959b-0c2c0995b16e


- **从剪切板导入JSON数据**
    - **创建任务：** 将数据作为新卡片追加到末尾。
    - **追加模块：** 追加到现有任务卡片，超出时自动新建。
    - **追加模块到选中：** 严格按 1对1 顺序追加到当前选中的卡片内。
- **从本地文件导入JSON数据**
    - 同上（创建任务 / 追加模块 / 追加模块到选中）。

## 📤 导出

进入预览窗口，在当前模式右侧的参数栏下载、整理或导出数据。左侧来源与显示字段决定处理范围。

- **下载媒体**。选择打包 ZIP 或保存到文件夹，点击下载全部或下载选中。勾选历史选项可扩展记录范围。
- **收集整理**。点击复制到子文件夹，将媒体复制到 ComfyUI 输出目录下的归档子文件夹。
- **导出 JSON 数据**。选择输入模块、输出模块或输入+输出模块，再点击复制或下载。历史选项将输出文件路径扩展为数组。
- **版式导出**。明细表、参数表和 XY 矩阵的右栏提供 PNG、HTML 等对应格式的导出设置。

## ▶️ 运行

https://github.com/user-attachments/assets/293f831d-b290-43e9-8515-6b9aa75a7b85

- **运行：** 根据所选内容执行任务。
    - **选择“任务卡片”运行：** 注入输入参数，运行该卡片内所有的输出节点。
    - **选择“输入模块”运行：** 等同于选择卡片运行。
    - **选择“输出模块”运行：** 仅执行所选输出及其依赖节点。
- **运行参数快照：**
    - 点击运行时，保存当前卡片中已绑定节点参数的输入模块状态，作为本次任务的参数。
    - 生成成功并拿到文件路径后，才会把该次快照与该条历史记录绑定保存。
    - 如果运行报错、没有产出可保存媒体，或抓取失败，则不会留下这次快照记录。
- **运行期间切换工作区：** 结果和参数快照保存到任务发起时的工作区；运行使用点击时保存的输入参数与绑定。
- **运行全部：** 按顺序运行当前工作区的全部任务卡片。
- **运行次数：** 在运行按钮旁输入次数，按卡片顺序交叉循环。例如，卡片 A、B 运行 3 次，顺序为 `A → B → A → B → A → B`。

## ⚓ 数据维护与配置锚点

- **自动创建配置锚点**。首次编辑时，在 ComfyUI 当前画布视图中心或附近空位生成 `CLab_SystemConfig` 节点。已有节点直接复用。
- 在工具栏的「数据维护」菜单中可清理或重新同步记录。
- **清理失效记录 (全局)：** 检查历史记录并移除文件已丢失的记录。
- **重新同步记录 (全局)：** 重新加载媒体。用外部软件修改并覆盖文件后，可通过此功能更新面板预览。
- **媒体加载失败提示：** 文件丢失或无法加载时显示“Media Missing”占位；自动移除失效历史记录时，对应的输入参数快照也会同步移除。

## 🎛️ 多媒体组件

https://github.com/user-attachments/assets/896f42b5-838b-4f9d-a1cb-6c8999cfb38f


- **视频组件：**
    - **播放 / 暂停：** 单击视频画面；悬停、暂停或操作控件时显示控制条。
    - **调节进度：** 在画面上滚动鼠标滚轮，或点击进度条跳转；时间码显示为 `分:秒:帧 (MM:SS:FF)`。
    - **音量：** 悬停喇叭图标展开滑杆，向左增大、向右减小。静音时拖动滑块可恢复声音；没有音轨时，静音按钮不可用。
    - **播放速度：** 手动输入倍速或从下拉列表选择。
    - **全屏 / 画中画：** 点击对应按钮切换。
- **音频组件：**
    - 匹配媒体比例时使用紧凑波形播放器，也可关闭后手动调整比例与尺寸；支持播放、暂停、调节进度、音量和播放速度。
    - **播放 / 暂停：** 单击波形；下方进度条用于跳转和拖动进度。
    - **滚轮调节进度：** 在波形区域滚动鼠标滚轮，向前或向后调整播放位置；滚动时暂停，结束后恢复之前的播放状态。
    - 波形进入可见区域后按需读取并缓存；波形不可用时仍可播放音频。
- **文本组件：**
    - 支持抓取节点输出文字并自动保存为本地 `txt` 历史记录，可在模块内直接预览。
    - 支持语法高亮和 Markdown 预览；预览区根据文本高度调整，长文本可滚动查看。
    - **复制全文：** 悬停模块后，点击右上角“尺寸与显示”齿轮左侧的复制图标；开启 Markdown 预览时仍复制原文。
- **底部信息：** 图片、视频显示实际分辨率，音频显示格式与时长，普通文件显示格式；历史序号统一在右下角，多条记录时显示。各模块的序号按自身记录计算，关联切换规则不变。
- **通用文件组件：**
    - 对于未提供专用预览的文件格式，显示文件名与“点击下载”链接；支持的文本格式由文本组件预览。
- **3D 模型与动作组件：**
    - **输入预览：** 开启“查看 3D”，在上传区预览模型。
    - **输出预览：** 支持标准 3D 文件列表和旧版预览节点返回；运行后直接在模块内预览；通过右键菜单的“预览模式”打开独立窗口，沿用历史记录、下载与关联切换规则。
    - **静态格式：** GLB / glTF 2.0、FBX、OBJ、STL、普通 PLY 网格与点云；BVH 以骨架显示。
    - **视角操作：** 在 3D 预览区内左键拖动旋转，中键或右键拖动平移，滚轮缩放；预览区外拖动仍用于移动模块。右键单击打开菜单，右键拖动平移时不弹出菜单。“重置视角”恢复初始视角。
    - **动画播放：** GLB / glTF、FBX 和 BVH 中的有效动作片段显示底部控制条，默认暂停。单击模型或播放按钮切换播放 / 暂停；可选择片段和播放速度。
    - **动画进度：** 底部进度条可拖动；`Shift＋滚轮` 前后调节，调节时暂停，结束后恢复原播放状态。暂停时停止逐帧刷新；暂时隐藏插件面板后重新打开，会恢复对应预览的位置、片段、速度和播放状态。
    - **配套资源：** 外置 `.bin`、MTL 和贴图需保持原有相对目录结构。归档时将已找到的配套文件复制到独立模型目录，保留引用关系；缺少贴图会提示，模型仍尽量显示。
    - **支持限制：** 暂不包含 Draco / Meshopt / KTX2 解码、高斯泼溅 PLY 及专用 NPZ 动作数据适配。“保存 GLB”接收已有文件时可能保留原格式，需以实际扩展名为准。
    - **资源管理：** 本地按需加载查看器，静止或暂停时不持续渲染；收起预览、移出可见区或关闭面板时释放模型、贴图、动画和 WebGL 资源。
- **生成记录管理：**
    - **视频缩略图：** 固定使用静音起始画面、按需预载元数据，不自动循环播放。
    - **多选与批量移除：** 网格中支持 `Ctrl/Cmd` 点选、`Shift` 区间连选；点击已选缩略图右上角的 `✖`，批量移除所选记录。
    - **拖拽排序：** 拖动缩略图可调整历史记录顺序，对应的输入参数快照随记录一起移动。

## 🔎 预览模式

从工作区工具栏最右侧点击「预览」。任务卡片默认进入「浏览」，参数表和 XY 矩阵直接进入对应页面。预览窗口顶部标签栏与工作区共用切换、拖拽排序、双击重命名、右键菜单及模式切换操作，模式栏居中可切换浏览、比较、明细表、参数表和 XY 矩阵。点击右上角的「工作区」返回。通过输出模块或任务卡片的右键菜单打开时，默认浏览所选结果。

### 多工作区预览来源

点击右上角「增加预览来源」勾选工作区，也可在预览标签栏用 `Ctrl/Cmd` 加选、`Shift` 连选。活动标签上方显示彩虹细线，多选后生长为所选标签的边框，连续标签合并外边框。普通单击标签恢复该工作区的单一来源。来源选择只改变预览范围，不合并工作区或扩大运行范围。

打开预览的默认落点为：任务卡片进入「浏览」，参数表进入「参数表」，XY 矩阵进入「XY 矩阵」。在预览中切换工作区时，优先保留当前查看模式；同类型或兼容的工作区之间切换不重置模式。只有参数表与 XY 矩阵工作区之间发生类型冲突，或当前查看模式不适用于目标工作区时，才使用目标的默认落点。例如，任务卡片的比较模式切到另一任务卡片仍是比较；参数表的浏览模式切到 XY 矩阵工作区则进入 XY 矩阵。预览里的参数表／XY 矩阵入口仍遵循工作区结构类型限制；混选这两类来源时，两种专属模式均置灰，仍可使用浏览、比较和明细表。

五个模式的来源栏左侧提供悬浮定位尺：长刻度表示工作区，短刻度表示来源列表中的任务，等粗、左对齐、固定间距。刻度尺居中显示，最多占来源栏高度的三分之二，超出后可用滚轮单独滚动；浏览来源时对应刻度加粗高亮。悬停查看标题和可用的缩略预览，点击展开并定位对应来源，不改变中央预览内容。

- **浏览、比较**。左侧按工作区、任务、输出模块分组，可跨工作区选择 A/B 媒体。
- **明细表**。任务卡片按工作区分区显示，保留各工作区的内容、封面及字段选择。
- **参数表**。各工作区按原有列结构横向拼接，顶部合并标题显示工作区名称。左侧每个工作区可折叠，任务与字段分两列勾选。点击工作区标题选中该分区，右侧设置作用于该分区；未选中分区时作用于所有来源。单元格选择后可继续局部调整，标题和外观修改同步回原工作区。
- **XY 矩阵**。各工作区在点状画布中独立分组，左上角工作区名和旁边的 Z 轴摘要随画布缩放。平铺时点击层标题或格子选中对应矩阵，点击工作区名选中其全部矩阵，点击空白处取消；蓝色标题表示选中，点击标题保留平铺。右侧参数调整选中的矩阵；未选中时调整所有来源工作区。左侧仅在选中格子时显示一处“当前格子”。多来源共用独立的总览视角，不覆盖单工作区的缩放和平移位置，导出包含当前显示的各组矩阵。

### 数据维护与归档

工作区工具栏及预览右上角的「数据维护」打开同一个浮动面板，操作范围明确显示为当前活动工作区。上方提供清理失效记录、重新同步记录；下方管理已归档任务，支持全选、恢复和删除。

移除 XYZ 取值后，对应任务退出当前任务列表。有结果、运行记录或手动修改的任务进入归档；尚未运行且未修改的自动任务直接清理。再次加入相同参数组合会复用归档中的任务及历史。手动恢复到矩阵时会补回相应轴取值，若连带增加其他组合会提示。删除归档只移除插件中的任务与历史引用，保留磁盘上的媒体文件。

### 下载媒体

五个预览模式的右侧参数栏都提供「下载全部」和「下载选中」。浏览默认下载各组封面，或下载中央正在预览的媒体。比较的「下载选中」下载当前 A/B 两侧。勾选「含组内全部记录」后，下载范围扩展到对应组。下载全部时按当前来源和类型筛选，比较中下载选中以当前 A/B 为准。

明细表按可见卡片或当前选中卡片下载内容媒体。参数表和 XY 矩阵按可见输出或选中区域下载当前显示的记录，勾选「含所有生成记录」后可下载相应输出的全部历史。在参数表或工作区 XY 矩阵预览中选中输出格后，可按方向键切换预览记录。

文件以「任务编号-输出模块编号-历史编号」命名。选择「打包 ZIP」会生成一个压缩包。支持文件夹访问的浏览器可以选择「保存到文件夹」，每批只选一次位置，同名文件会加编号。

### 收集整理与 JSON 数据

五个预览模式的右侧参数栏提供「收集整理」和「导出 JSON 数据」，均按当前模式可见的任务与模块取值。勾选各自的「含组内全部记录」可扩展历史范围。

- **收集整理**。点击「复制到子文件夹」，将当前范围的 ComfyUI 媒体复制到输出目录下的「归档目录／工作流名_工作区名」中。文件使用任务、输出模块和历史编号命名。
- **导出 JSON 数据**。选择输入模块、输出模块或输入+输出模块，再点击复制或下载。JSON 沿用按任务排列、以模块标题作为字段名的格式，同名字段自动追加序号。参数表采用当前勾选的任务与字段，明细表采用显示中的字段值。

### 浏览布局与来源筛选

- **左侧来源：** 列出当前工作区的任务卡片及输出模块，名称与卡片、模块标题一致，未命名时显示 `#1`、`##1` 等默认标题。显示各模块的历史数量；没有记录的模块仍显示，复选框禁用。进入时默认勾选所选模块或卡片的输出。
- **任务勾选：** 点击任务名称或复选框，批量选择或取消其有记录的输出模块；部分模块选中时显示半选状态。点击名称左侧的小三角展开或折叠。支持搜索任务、模块，以及全选或取消全部来源。
- **中间预览、右侧参数：** 中间查看当前媒体，右侧显示该记录保存的输入参数。拖动两条竖向分割线调整面板宽度；达到最小宽度后继续向边缘拖动可收起，点击边缘三角恢复默认宽度。
- **视频预览：** 使用模块内的视频控件和交互：单击画面或按空格播放 / 暂停，滚轮调节进度，点击底部进度条跳转；`Ctrl＋滚轮` 朝鼠标位置缩放，左键拖动画面平移。支持音量、倍速、画中画与全屏，首次加载保持暂停，手动播放；编辑输入框时空格不触发播放。
- **模块封面与历史**。每个输出模块先显示大封面，名称位于封面左下角，标题过长时省略；记录总数位于右下角。悬停封面时隐藏数量，在同一位置显示正序／倒序按钮，点击仅反转当前模块的历史顺序并同步到工作区，不切换当前预览。复选框位于封面左侧并与封面顶部对齐。模块复选框与任务复选框左对齐，封面与任务标题文字左对齐；任务折叠三角下方保留竖向虚线。任务和已勾选模块的历史默认全部展开，任务可通过三角按钮手动折叠。取消勾选后封面灰显，历史记录收起。
- **封面与缩略图比例**。每个模块按历史图片、视频的真实宽高比排序，取中位项作为统一比例；偶数条时取中间偏小的一项。比例最低为 1:1，竖向媒体使用正方形外框；内容保持原始比例完整显示。媒体尺寸在模块进入可见区域后读取，尚无可用尺寸时使用 16:10。
- **设置封面**。默认使用最新记录。点击历史缩略图左上角的封面图标，或在中央预览区右键选择「设为封面」，更新上方大封面。对应记录继续保留在历史列表中，其封面图标常亮。再次点击当前封面图标可恢复使用最新记录。
- **历史排序与分组**。任务、模块始终跟随工作区原顺序，空模块保留原位。模块内拖动历史缩略图排序，会同步到工作区对应输出模块，运行编号、参数快照、文本记录和当前选中记录一并保持对应。跨模块拖动仅改变预览分组，保留原始输出模块的历史归属。Ctrl/Cmd 点选或 Shift 连选可批量拖动。
- **左栏控件**。搜索框左侧选择媒体类型，右侧继续搜索任务或模块。“全选、取消”右侧显示模块与记录统计，空间不足时省略，悬停可查看完整信息。左栏滚轮纵向浏览，缩略图默认两列，可通过滑杆调整为 1～6 列，点击网格图标恢复两列。
- **局部更新：** 来源搜索、排序、分区选择、区域拖拽和缩略图尺寸调整不会重建未切换的中央预览，保留视频播放位置、暂停状态及 3D 视角。

### 浏览与 A/B 比较

- **浏览：** 左键拖动图片可平移。`←` / `→` 沿缩略图顺序切换，到达组边界时继续到相邻组。`↑` / `↓` 跳到相邻组上次浏览的记录，首次进入时打开封面。`Shift＋←` / `Shift＋→` 仅切换当前输出模块。
- **比较布局：** 与“浏览”共用左侧来源与媒体面板，支持来源搜索、勾选、分区排序、缩略图尺寸调整，以及分割线拖拽和区域收起；仅展示可用于对比的图片与视频。
- **选择 A/B：** 点击左栏封面或历史缩略图，添加或替换当前待选区域，并自动切换到另一侧；也可直接拖动缩略图到指定的 A 或 B 区域。支持同一模块、不同输出模块或不同任务的两张图片、两个视频。缩略图右上角使用微圆角正方形标记 A/B，同一记录用于两侧时分别显示两个标记。
- **媒体信息：** 预览区左上角显示“A | 任务 · 模块 · 历史”，右上角显示“任务 · 模块 · 历史 | B”，信息不带背景框；点击信息可指定待替换区域，对应 A/B 编号的微圆角正方形底色与字母亮起。信息、交换按钮及视频控件覆盖在媒体上，放大图片时仍可操作，悬浮控件不使用投影。
- **并排比较 / 分屏比较：** 在媒体底部悬浮的小号胶囊中点击切换，胶囊位于左侧操作提示上方，当前模式以高亮和粗体标识，图片可铺满按钮后方区域。并排显示两条结果，或将两者叠放，鼠标在画面上移动分界线查看两边内容。
- **交换 A/B：** 点击分割线中间的空心圆，圆内为实心双向箭头，圆的上下描边与分割线相连；圆的可见直径为 22px，透明点击范围略大。分屏时圆随分界线移动，悬停时保持位置，便于点击；悬停或键盘聚焦时箭头与圆环变白，圆环略微加粗。
- **图片操作：** 滚轮同步缩放，左键拖动同步平移。
- **视频操作：** 与模块内复用相同的视频控件，单击画面或按空格同步播放 / 暂停，点击底部进度条跳转，滚轮同步调节进度；`Ctrl＋滚轮` 朝鼠标位置同步缩放，左键拖动同步平移。两段视频共用倍速与有效时长，声音可选 A、B 或静音，支持音量、画中画与全屏。首次加载保持暂停，手动播放。
- **参数对照：** 右侧显示各自运行时的输入参数，突出不同值。A/B 选样不切换卡片历史，也不回填当前输入值；切换待选区域、对比布局及来源筛选时复用未更换的对比媒体，交换视频时保留进度与播放状态。

### 明细表

- **保存设置：** 封面、内容模块及历史位置、任务与字段勾选、缩略图列数和明细表样式随各自工作区保存到工作流；返回工作区或重新打开后恢复。已删除的任务、模块及历史记录会自动清理对应引用，失效封面恢复为内容预览。
- **来源与任务预览：** 默认勾选全部任务。任务标题下显示内容预览；指定封面后，封面在前、内容向右下方露出，形成两层预览。点击两层分别打开封面或内容记录池。下方按输出模块排列历史缩略图，再列出可多选的输入字段，包含仍有历史快照的已删除字段。顶部可调整缩略图列数，默认两列。
- **搜索与筛选：** 在搜索框左侧选择媒体类型，再搜索任务或模块名称。筛选仅改变左侧来源列表，不改变已勾选任务、中间卡片及导出范围，也不会取消已选内容或封面。
- **内容选择：** 单击输出模块的单选框或名称选择内容模块，保留其上次浏览的记录。单击下方某条缩略图，同时选择该模块和这条内容记录；历史参数随内容切换，工作区原值不变。按 `←`、`→` 在模块内切换历史，到达首尾后跳到来源列表中相邻输出模块的第一条记录；按 `↑`、`↓` 直接跳到上一个、下一个有记录的输出模块，遵循当前来源筛选，封面不随之改变。
- **封面选择：** 悬停历史缩略图，点击左上角图标将该条记录设为当前任务封面，图标常亮；再次点击取消。封面不影响内容模块的单选状态，也不会被新生成的记录替换。没有封面或封面记录被删除时恢复内容预览。卡片悬停时显示原内容，视频需手动播放；移开后暂停并显示封面，保留进度。
- **同名模块批量应用：** 悬停输出模块的标题或历史缩略图区域，点击右侧“批量应用”按钮，可选择“将同名模块设为内容”或“使用同名模块图片作封面”，作用于当前勾选任务。内容按同名模块切换；封面保留发起任务已选的同模块记录，其他任务使用各自同名模块的最新图片，没有可用图片时跳过。已应用的同名封面可从同一菜单取消。未命名模块按 `##1`、`##2` 匹配；同名模块有多个时，发起任务使用所点击模块，其他任务优先保留已选模块。
- **记录池：** 卡片标题右侧的封面、内容入口和左侧任务叠层预览均可打开记录池。面板靠近入口展开，空间不足时向上展开；选择记录后保持打开，点击外部、关闭按钮或再次点击入口关闭。顶部可切换输出模块，并按封面或内容用途批量应用。`Esc` 仅关闭记录池。下方输入字段始终跟随内容记录，选择封面不改变参数快照。
- **同名字段显示：** 点击输入字段的复选框或名称，仅切换当前卡片的字段。悬停字段行后，右侧显示“眼睛＋叠层”按钮，点击可批量切换当前勾选任务中的同名字段；全部显示时点击会全部隐藏，部分显示或全部隐藏时点击会全部显示。悬停按钮可查看具体操作，字段显示调整会同步到 PNG 和 HTML 导出。
- **快捷隐藏字段：** 悬停预览卡片的字段，右上角显示两个图标：斜线眼睛仅隐藏当前卡片的此字段，带叠层标记的斜线眼睛隐藏当前勾选任务中的所有同名字段。按钮只操作所在字段，保留其他已选字段；可从左侧来源区重新显示，原参数和历史记录不变，图标不参与导出。
- **选择联动定位：** 单击卡片标题只选中卡片，左侧定位并高亮对应任务；单击字段定位对应来源字段，折叠任务自动展开。目标已经可见时不滚动，超出视野时尽量滚动到面板中央；到达列表顶端或底端时自然停止，不额外留白强行居中。多选时定位最后点击的字段，`Shift` 连选定位终点，来源勾选状态保持不变；目标被来源搜索或类型筛选隐藏时，清除筛选后定位。
- **来源定位卡片：** 点击来源栏工作区区域，中央明细表定位到对应工作区；点击任务范围内的空白、字段、缩略图或按钮，定位到该任务卡片。原有的勾选、封面和记录选择操作保持有效。
- **卡片预览：** 每个任务一张卡片，上方显示任务标题和封面、生成记录位置，中间复用图片、视频、音频、文本或 3D 预览组件，下方排列输入字段。点击卡片后，`←` / `→` 切换该卡片的预览历史；视频空格键仅操作当前卡片，编辑输入框或记录池打开时不触发底层播放。
- **历史参数：** 数据区的 Key 为输入模块标题，Value 为该条历史的参数值，默认行内排列。切换历史同步切换对应快照；旧记录缺少快照时显示“参数未记录”，不会用当前值替代。尚无输出的任务显示当前参数，并明确标注。新生成记录也保存未绑定节点的备注等输入字段。
- **布局：** “整行宽度”控制一行卡片及间距的总宽度，调整列数时保持总宽度不变，卡片均分剩余空间。卡片在预览区居中，同一行等高；图片、视频按原比例铺满卡片宽度。超出可视区域时可滚动查看。左右分割线可拖动调整、收起，并通过三角按钮恢复；布局和样式调整保留未切换的播放器、暂停位置和 3D 画布。
- **字段样式：** 单击数据行选中字段；`Ctrl/Cmd` 点击加选或取消，`Shift` 按卡片、字段顺序连续选择；点击预览区或卡片内空白处取消选中。在右侧选择“整行 / 标题 Key / 内容 Value”，批量设置颜色、字号、文字行距（字号倍数）、字段间距（px）、加粗、斜体、下划线、删除线；字段间距只调整该字段到下一条可见字段的距离，最后一条字段不生效；大小写、对齐和行内 / 块级布局使用图标切换，悬停查看说明。标题和内容默认均为灰色。块级布局旁的“间距”控制 Key 与 Value 的间距（px），仅块级布局时可编辑，切回行内保留设置值。
- **应用范围：** 勾选“仅当前字段”修改当前选中的字段，或“所有同名字段”（默认）批量修改这些名称对应的字段，两者互斥；支持恢复样式。排版与文字样式保存在浏览器本地，大小写只影响展示和导出，不改写原始参数。
- **PNG：** 按当前列数、整行宽度与字段样式，复制或下载一张完整 PNG。导出中间预览区显示的全部卡片，通过左侧来源勾选控制范围。放大倍数默认 3 倍。有独立封面时使用封面；否则视频和 3D 使用当前画面，音频使用波形。保留中文与换行；明细表、参数表和 XY 矩阵共用 PNG 导出，大图分块渲染、逐步压缩成一张图片，不再按原来的固定总像素及单边尺寸提前拒绝。内容越多、倍数越高，导出耗时越长。
- **离线 HTML：** 打包当前勾选的任务、输出、封面及输入字段，可选择包含所选输出的全部历史。解压后打开 `index.html`，无需原 ComfyUI 服务或 CDN，支持历史与参数同步切换、封面切换及视频手动播放，以及音频、文本和 3D 查看。媒体及配套资源封装在 `assets` 脚本中，避免本地文件页面直接读取媒体数据的限制；缺失配套资源会提示。未勾选字段不加入页面的明细数据。

### 预览窗口的参数表

沿用工作区的表格、行列尺寸、内边距与对齐方式。左栏列出所有任务和字段，默认勾选有效区域。双击列名可以改名，右栏的「单元格设置」可修改所选单元格的样式。改名和样式会同步到工作区。

- **PNG**。按预览的表格尺寸、比例和样式渲染，列头只显示标题。可设置放大倍数，并复制到剪贴板或直接下载一张 PNG。
- **Excel**。导出 `.xlsx`，保留可编辑的单元格内容与行列尺寸，并将可见图片嵌入相应单元格的位置。超出 Excel 行高或列宽上限时按上限导出。
- **离线 HTML**。打包当前显示的表格和媒体，解压后打开 `index.html`。

### 预览窗口的 XY 矩阵

- **工作区矩阵**沿用工作区画布和每格正在显示的记录。
  - **左栏**。勾选 X、Y 轴取值筛选并收拢行列，支持全选和取消。附加记录参数的勾选随工作区保存。选中格子可查看任务、输出模块、历史位置、完整轴取值及附加参数；附加参数取自当前历史，未保存时明确提示。勾选的参数在 Z 轴摘要旁集中显示为半透明记录表，分为节点名称、参数名称、参数值三列。同值合并，不同值分别列出；默认长名称省略、参数值最多显示两行；勾选“显示全部内容”后，三列限制宽度并完整换行，开关随工作区保存。悬停可查看完整内容，原始记录不截断。
  - **画布**。单层时点击 Z 轴取值切层；通过工作区工具栏或预览右栏的“平铺所有 Z 层”展开全部层。工具栏启用平铺后显示设置齿轮，预览侧则直接在复选框下展开列数及并排的行列间距设置。状态和布局按工作区同步，切换时保留视图及运行范围；平铺时隐藏 Z 轴及取值，将唯一的 Z 轴绑定摘要放到整组矩阵上方、靠左的公共标题区，保留各层取值标题；单层时摘要回到 Z 轴末端。每层 Z 轴标题限制在该层矩阵宽度内居中，长文本自动换行并向上展开，避开绑定摘要。缩放和平移与当前工作区双向同步，进入、返回或重新打开预览时沿用同一视图；需要重新居中时点击“适配视图”。与工作区共用操作：左键单击选格子，`Ctrl/Cmd` 加选，`Shift` 矩形连选；左键拖动格子、坐标轴或空白处平移，中键拖动平移，滚轮缩放。媒体内部的播放控件及 3D 旋转保留各自操作，`Ctrl＋滚轮` 可缩放矩阵。
  - **右栏**。分别设置 X、Y、Z 轴及其绑定摘要的可见性，调整间距、边距、对齐原点、角度、Y 轴方向和轴交换。
- **按历史参数重排**从左侧勾选输出来源，在右侧选择历史参数作为 X、Y 和可选的 Z 轴。缺失组合留空，同一组合可保留多条记录。
- 两种来源均可设置 PNG 放大倍数，复制或直接下载整张图，也可打包离线 HTML。工作区矩阵按画布排布导出勾选的 X／Y 范围、所选 Z 层和可见的坐标轴与摘要；筛选与切层仅影响预览和导出，不改动工作区任务。按历史参数重排时，还可调整媒体宽度和文字长度。

## 👁️ 界面适配

- **工作区工具栏**。三个模式默认停靠在顶部。拖动工具栏空白处可横向悬浮，或吸附到顶部、底部。切换模式或工作区时沿用同一位置。任务卡片和参数表的选中项工具在停靠时居中，悬浮时独立显示。右键点击工作区栏空白处，可选择「在上方」或「在下方」。

## ⚙️ 核心偏好设置 (Settings)

点击 ComfyUI 设置齿轮（Settings），在 **`Creative Lab`** 分组中调整以下选项：

![设置界面](images/setting.png)

### 1. 常规 (General)

工作区与预览面板共用宽度、高度、背景不透明度和毛玻璃设置，修改后同时生效。

- **新建工作区的默认模式**可选任务卡片、参数表或 XY 矩阵。
- **恢复全部默认设置**：一键将面板内的所有 CLab 选项重置为出厂状态。
- **快捷键**：自定义呼出/隐藏面板的组合键（支持单字母或 `Shift+C` 等组合键）。
- **拾取节点快捷键 (Node Picker Shortcut)**：默认为 `P`，支持自定义组合键，留空可禁用。
- **启用背景毛玻璃效果**：开启或关闭面板背景模糊。
- **面板背景不透明度**：在 0%~100% 之间调整。
- **面板宽度 / 高度比例**：分别设置面板相对浏览器窗口的宽、高比例，默认均为 92%，可在 40%~100% 之间调整。

### 2. 性能与媒体播放 (Performance & Media)

- **历史记录容量上限**：设置单个输出模块最多保存的记录数，超出后移除最旧记录及对应的输入参数快照。
- **切换历史时同步参数 (Sync Parameters on History Switch)**：默认开启，切换输出历史时回填该条记录的输入参数；关闭后仅切换输出预览。
- **视频默认静音**：设定新加载主视频的初始静音状态，保留已有播放器的手动选择；比较模式独立选择 A/B 声音，缩略图固定静音。视频首次加载不自动播放，历史缩略图固定显示静帧。

### 3. 文件与数据流转 (File & Data I/O)

- **归档文件夹名称**：设置自动归档和整理文件的根目录，默认为 `CLab`。
- **是否保留原临时文件**：关闭后，归档完成时删除原临时文件。
- **生成文件名前缀**：设置归档文件的名前缀，默认为 `pix`。

### 4. 自动化行为 (Automation)

- **连续运行异常阻断**：默认开启，任务校验或运行报错时停止本次批次的后续任务，并取消该批次已提交的后续排队项。关闭后跳过出错任务继续执行；其他批次和 ComfyUI 原生队列中的无关任务保持原有状态。

### 5. 任务卡片选中态外观 (Card Appearance)

- 可自定义卡片选中时的发光、填充、描边与高亮色。默认：**描边 1 px、填充透明度 0%、发光强度 10、高亮色 #4CAF50**。

### 6. 模块选中态外观 (Module Appearance)

- 独立自定义模块（输入/输出区）被点击选中时的反馈效果，包含：**发光强度**、**填充透明度 (%)**、**描边粗细 (px)** 以及 **高亮主题色**（默认亮蓝）。

### 7. 任务卡片

- 卡片间距、模块间距和卡片内边距即时生效。默认卡片宽度用于首次打开和点击「恢复默认宽度」。

### 8. 参数表

- 设置新工作区的默认列宽、行高和单元格内边距。

### 9. XY 矩阵

- 设置新工作区的默认 Y 轴方向、格子间距及坐标轴到格子的距离。
