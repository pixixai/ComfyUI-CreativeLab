# 开发指南

本文对应 v1.0.2，描述当前维护入口和约束。版本演进见 [局部微创更新重构记录](局部微创更新重构记录.md)，逐项功能入口见 [开发者功能映射手册](开发者功能映射手册.md)。

## 架构与数据边界

前端是原生 JavaScript 模块，后端通过 ComfyUI 注册配置节点和本地资产接口。三种工作区共用任务与模块模型，五种预览页面读取这些任务的历史，并按需要同步标题、顺序或版式设置。

- `web/components/ui_state.js`：schema v4、工作区列表、活动工作区镜像、旧通道迁移及保存入口。
- `web/state_manager.js`、`web/config_storage.js`：工作流节点配置的编码、加载、合并写回及前端轻量显示。
- `web/components/workspace_modes/`：卡片、参数表、XY 的视图、输入、选区及布局控制器。
- `web/components/contextmenu/content/preview_*.js`：五种预览、来源、多工作区、下载与导出。
- `web/api_injector.js`：运行快照、参数注入、动态剪枝、结果回填、有界排队和打断。
- `api.py`：本地资产复制、整理、文本保存、历史扫描及使用系统软件打开资源等接口。
- `nodes/config_node.py`：`CLab_SystemConfig` 的后端定义，不承担生成处理或前端排队调度。

工作区、任务、模块使用稳定 ID。`state.cards` 是活动工作区的镜像，不能把它当作所有工作区的数据，更不能在后台任务回传时按当前活动工作区猜测结果归属。

## 工作区模式与预览

`workspace_modes.js` 编排 `mode_cards.js`、`mode_table.js` 和 `xy_controller.js`。参数表与 XY 保留独立结构类型，`mode_policy.js` 约束切换，不能经卡片视图绕过互转限制。

`preview_modal.js` 编排浏览、比较、明细表、参数表及 XY。多来源预览建立可回写的工作区映射，操作时带上所属工作区；不要将预览中的临时标识直接写回另一个工作区。

- 参数表预览允许改名、行列排序和单元格外观，不提供生成参数绑定或批量填值。
- XY 预览共享矩阵布局，来源筛选不删除原任务，多来源总览视角不覆盖单工作区视角。
- 明细表会保存封面、内容、字段、记录选择和样式；不是仅存在于一次弹窗中的临时配置。
- 预览不是所有数据都只读，查看操作与内容编辑要使用不同保存、撤销链路。

## 局部更新与按需加载

新增功能优先修改目标对象和相关视图，避免无变化时重建整个列表或重新初始化播放器。

| 入口 | 用途 |
| --- | --- |
| `comp_modulearea.js` | 模块生成、刷新调度及事件装配 |
| `module_lifecycle.js` | 模块资源清理、在容器之间安全移动现有 DOM |
| `card_window.js`、`card_window_geometry.js` | 当前卡片窗口、缓冲范围及未挂载任务定位 |
| `card_layout.js`、`input_measure.js` | 布局预排、文本高度测量与失效判断 |
| `viewport_components.js` | 可见单元格／模块的装载、缓存及状态恢复 |
| `card_cache.js`、`cache_preferences.js` | 有上限的最近卡片及各类组件缓存 |
| `media_dimensions.js` | 合并相同 URL 的媒体尺寸探测 |
| `frame_work.js`、`panel_loading.js` | 可取消的分帧任务与面板渐进显示 |
| `card_navigation.js`、`card_navigation_plan.js` | 近距离平滑、远距离分段定位 |

选择、运行、克隆、删除及 Shift 范围选择都根据完整数据计算，不依赖当前 DOM 是否挂载。正在编辑、上传或拖拽的对象要保留必要状态。大量媒体不能仅通过 `display:none` 隐藏后长期留在后台播放、解码或渲染。

同一 DOM 节点不能同时出现在两张卡片。共享定义与尺寸结果可以减少准备工作，但输入值、绑定、媒体状态仍属于各个模块。资源缓存仅存在于浏览器，不进入工作流配置。

## 保存与撤销

- 普通编辑合并保存，视图保存等待空闲；运行、关闭面板、保存工作流等关键时刻调用补存。
- `StateManager` 按工作区复用序列化结果，不改动外部工作流格式。`scenes_data` 数据值仍保存完整 JSON，文本框只显示简短说明。
- `edit_history.js`、`history_snapshot.js` 维护按工作区隔离的内容差量；`edit_history_runtime.js` 接管快捷键、保存范围和恢复事件。
- `history_context.js` 规划撤销结果在哪个界面展示；当前界面可展示时不切换。
- `history_tasks.js` 保留撤销退出列表但已有结果或提交记录的任务，允许迟到结果继续写回。
- 来源筛选、选择、缩放、平移及历史查看不进入内容撤销；文字输入框继续原生文字撤销。记录到顶后不泄漏到 ComfyUI 的工作流历史。

工作区删除与媒体删除不是同一个动作；任务归档、恢复和永久移除引用应经过对应模型接口。

## 执行与结果

各模式先构建任务范围，交叉展开次数，再由 `CLab.executeTasks()` 冻结输入和绑定。`execution_queue.js` 默认最多保留五个未完成提交，完成后补位；不要恢复为对全部任务同步编译和提交。

结果通过 prompt ID 绑定发起任务。文件转存未完成前保留映射；引擎结束则可释放提交名额，两者不能混为同一个生命周期。报错停止取消所属批次，主动打断取消插件所有工作区批次，并按 ID 定向取消后台请求。

历史变更必须同时维护媒体、文本、输入快照和运行关联。优先使用 `media_utils.js` 与历史维护模块，避免直接改一组数组后使对应关系错位。细节见 [批处理机制](运行次数与批处理机制.md) 与 [资产同步](资产管理与状态同步原理.md)。

## 拾取、菜单与媒体事件

- `action_binding.js` 解析节点、参数及 Primitive 下游映射，并负责隐藏／恢复面板和拦截工作流点击。
- 卡片模块复用委托事件；表头及轴摘要通过共享中键手势入口调用各自绑定模型。轴摘要之外的中键仍用于平移。
- 中键直接完成有效参数绑定后回到工作区，不强制重开绑定面板；从面板拾取按钮进入则恢复原面板。XY 只拾取节点本体时继续提示选择参数。
- 工具栏空白处的 `pointerdown.preventDefault()` 用于拖动，可能抑制 `mousedown`；外部点击关闭菜单在捕获阶段监听 `pointerdown`，不能只依赖后续鼠标事件。
- 视频、音频、文本及模型分别由 `modules/media_types/` 的渲染器处理。模型查看器延迟加载，隐藏暂停、到期回收；媒体事件清理使用生命周期回调或可取消监听。

## 导出与后端约束

PNG 共用 `preview_png.js` 的分块渲染和 PNG 编码，布局导出及明细表导出分别准备媒体静帧。不要为了某个页面引入另一套会丢失中文、样式或离屏媒体的截图流程。

HTML 包依赖 `web/vendor/` 的本地资源；新增离线交互时同步检查打包入口。Excel 由 `preview_xlsx.js` 输出，图像和行列尺寸还受 Excel 格式限制。

后端路径必须验证目录边界；媒体上传、整理、打开文件沿用已有接口，不执行用户输入的任意命令。不要用前端缓存或工作流 JSON 代替媒体文件的备份。

## 验证

在插件目录运行：

```powershell
node --test tests/*.test.mjs
$env:CLAB_BROWSER_SUITE='binding-gestures'
node tests/performance.browser.mjs
```

浏览器场景使用独立测试页面，不占用用户的实际工作流或 GPU 生成。可按修改范围选择 `run`、`menus`、`history`、`editing`、`follow`、`card-window`、`ruler-jump`、`viewport`、`card-cache` 或 `progressive` 等专项。新增设置同时维护中文本地化；涉及用户操作时同步更新对应使用文档。
