# 预览模式

预览模式用于查看、比较和整理已经生成的结果，共有「浏览、比较、明细表、参数表、XY 矩阵」五个页面。它不会代替工作区提交生成任务；部分标题、排版、历史顺序和记录选择会与工作区同步。

本文对应 v1.0.2。工作区操作另见 [任务卡片](任务卡片.md)、[参数表](参数表.md)、[XY 矩阵](XY矩阵.md)。

## 进入、切换与退出

1. 点击工作区工具栏最右侧的「预览」；也可从任务卡片或输出模块的右键菜单打开。
2. 在顶部模式栏中间选择预览页面。任务卡片工作区初次默认进入「浏览」，参数表和 XY 矩阵工作区默认进入各自同名页面。右键进入时默认浏览所选卡片或模块的输出。
3. 点击右上角「工作区」返回；`Esc` 可关闭预览，记录池等子面板打开时先处理子面板的关闭。

预览中的工作区标签栏支持单击切换、双击改名、拖拽排序和右键菜单。切换工作区时，兼容情况下保留当前预览页面。例如，两个任务卡片工作区之间切换可继续停留在「比较」。参数表工作区与 XY 矩阵工作区直接切换发生结构冲突时，使用目标工作区的默认页面。

参数表与 XY 矩阵的结构类型不互转，包括经任务卡片中转；不兼容的入口置灰。混选两类结构来源时，仍可使用浏览、比较、明细表，两种专属表格页面不可同时启用。

## 共用布局与来源

### 区域与面板

- **顶部**：中央切换五种模式，右侧增加预览来源、打开数据维护或返回工作区。
- **工作区标签栏**：与工作区界面共用工作区名称及顺序，位置随工作区栏设置。
- **左侧来源**：选择参与查看的工作区、任务、输出或字段，具体内容随模式变化。
- **中央**：显示媒体、比较画面或排版后的卡片、表格、矩阵。
- **右侧参数**：显示参数快照或版式设置，下方为当前模式的下载、整理及导出工具。

拖动左右分割线调整区域宽度，拖过最小宽度可收起侧栏，点击边缘三角恢复。来源、预览和参数区使用细滚动条。工作区与预览面板共用设置中的宽度比例、高度比例、背景不透明度与毛玻璃效果。

### 增加多个工作区

点击右上角「增加预览来源」，或在标签栏用 `Ctrl/Cmd` 加选、`Shift` 连选；普通单击标签恢复单工作区来源。活动标签显示彩虹线，多选时按连续标签形成彩虹边框。

- **浏览、比较、明细表**：按工作区分组罗列任务和输出。
- **参数表**：按各工作区的列结构横向拼接，工作区名显示在合并的顶层表头。
- **XY 矩阵**：各工作区的矩阵在同一总览画布中分组排列。

增加来源不合并工作区，也不扩大工作区的运行范围。

### 来源定位尺

左侧定位尺的长刻度表示工作区，短刻度表示列表中的任务。固定间距显示，最多占侧栏高度的三分之二，刻度过多可单独滚动。滚动来源时，对应刻度高亮。

悬停当前刻度伸长至 3 倍，相邻两档依次为 2.3 倍、1.6 倍；只有当前刻度变色。提示中显示位置标题和可用的缩略预览。点击刻度展开、滚动到对应来源；它与点击具体结果缩略图的操作不同。

## 浏览

适合逐条查看图片、视频、音频、文本和 3D，并核对该条结果保存的输入参数。

### 来源、封面与历史列表

- 来源按「工作区 → 任务 → 输出模块」排列，名称使用任务、模块标题，未命名时显示默认编号。
- 点击任务名称或复选框，勾选或取消其有记录的输出；小三角用于折叠任务。模块复选框只切换该模块。没有记录的模块保留原位，不能勾选。
- 搜索框左侧选择媒体类型，再输入任务或模块名称继续筛选。下方提供「全选、取消」及数量统计。
- 缩略图列数默认为 2，可调为 1～6；点击网格图标恢复默认。
- 模块先显示较大封面，下方显示勾选模块的全部历史缩略图。取消勾选后封面灰显，历史收起；其他任务不会因当前任务改变而自动折叠。

每个模块按其图片、视频历史的真实宽高比排序，取中间项作为封面及缩略图的共同外框比例；偶数条取中间偏小的一项，最窄为正方形。媒体保持自身比例完整显示。尺寸尚未读取时，使用临时的 16:10 外框。

### 封面与顺序

- **默认封面**：使用模块最新记录。
- **指定封面**：点击历史缩略图左上角的封面图标，或在中央媒体的右键菜单选择「设为封面」。记录仍留在历史列表，封面图标常亮；再次点击当前封面图标恢复默认封面。
- **反转历史**：模块封面左下角显示标题，右下角显示记录数。鼠标悬停该输出模块区域时，右下角数量变成正序／倒序按钮。点击会实际反转该模块的历史顺序，并同步工作区，不只是改变筛选显示。
- **拖拽排序**：模块内拖动历史会同步到工作区，并保持媒体、运行编号、参数快照及当前记录的对应关系。任务和模块本身仍跟随工作区顺序。
- **跨模块拖动**：改变预览的自定义分组，不将历史改挂到另一个工作区输出模块；与模块内历史重排区分。`Ctrl/Cmd` 点选、`Shift` 连选可用于批量拖动。

### 媒体与键盘操作

点击封面或历史缩略图，在中央查看结果；右侧显示该条历史的输入快照。旧记录没有快照时会明确提示。

| 操作 | 效果 |
| --- | --- |
| `← / →` | 前后切换记录，越过组边界进入相邻输出模块组 |
| `↑ / ↓` | 跳到相邻组上次浏览的位置，首次进入使用封面 |
| `Shift＋← / →` | 只切换当前输出模块的历史 |
| 图片上滚轮 | 朝鼠标位置缩放 |
| 图片或视频上左键拖动 | 平移画面 |
| 视频上单击或空格 | 播放／暂停；编辑输入框时不触发 |
| 视频上滚轮 | 调整播放进度；`Ctrl＋滚轮` 缩放画面 |

视频复用模块控制条，可调整音量、倍速、进度及全屏／画中画，首次加载不自动播放。音频、3D 沿用对应组件操作；3D 用左键旋转、中键或右键平移、滚轮缩放，`Shift＋滚轮` 调节动画进度。

文本支持语法高亮、Markdown 预览及复制原文。浏览页的文本编辑器修改后可点击「保存」，或按 `Ctrl/Cmd＋S` 写回对应文本文件；这是文件内容修改，不是重新生成一条记录。

搜索、调整来源及侧栏宽度时，未切换的中央媒体尽量复用，保留播放位置和 3D 视角。

## 比较

适合从同一输出的不同历史、不同任务或不同工作区中选出两张图片或两个视频进行 A/B 比较。图片和视频不能混合组成一对。

### 选择 A/B

1. 在左侧勾选来源，点击封面或历史缩略图，填入当前待选区域。
2. 选择后自动切换到另一侧；也可点击画面左上角 A、右上角 B 的信息区，指定下一次替换哪一侧。
3. 将缩略图拖入 A 或 B 区域，可以直接替换指定位置。

缩略图右上角标记当前 A/B；同一记录可用于两侧。来源搜索、封面、历史反转及拖拽规则与浏览页相同。

### 布局与画面操作

- **并排比较**：两份结果左右显示。
- **分屏比较**：两份结果叠加，鼠标移动分界线查看底层内容。
- **交换 A/B**：点击分割线中央的圆形双向箭头。分屏时按钮跟随分界线，悬停按钮时保持位置，方便点击。
- **同步缩放和平移**：图片上滚轮缩放、左键拖动平移，两侧同步。模式切换与信息按钮悬浮在媒体上，不占据额外画面高度。
- **视频同步**：单击画面或按空格播放／暂停，滚轮同步调进度，`Ctrl＋滚轮` 同步缩放。两段视频共用倍速和有效播放时长，声音可选 A、B 或静音。

底部悬浮胶囊切换并排／分屏。右侧对照两份历史的输入参数，突出不同值。选择 A/B 不切换工作区输出模块的当前历史，也不回填工作区输入；浏览页的记录切换则可能按设置回填参数。

## 明细表

适合把每个任务的一份输出与对应输入参数排成卡片，制作可分享的结果清单。

### 任务、内容与封面

默认勾选全部任务。每张卡片选择一个输出模块作为内容，并可选择一条独立记录作为封面；输入字段可以勾选多项。

- **左侧任务预览**：任务名称下方显示内容预览。有独立封面时，封面在前、内容向右下露出，形成叠层；点击两层分别打开各自记录池。
- **输出模块**：单选框或名称设置内容模块，点击历史缩略图选择内容记录。内容缩略图有底衬，封面记录的图标常亮。
- **独立封面**：悬停历史缩略图，点击封面图标指定该记录；封面可来自同一任务的另一输出模块。未设置封面时共用内容预览。
- **输入字段**：复选框决定当前卡片显示哪些字段，也可显示仍保存在历史快照中的已删除字段。
- **搜索与筛选**：沿用类型、任务／模块名称搜索及缩略图列数设置；筛选左侧列表本身不代替任务、字段的勾选。

悬停内容区域时显示内容，移开后暂停并恢复封面；视频首次显示仍需手动播放。封面选择不改变内容记录对应的参数快照。

### 记录池与批量应用

卡片右上角分别显示封面、内容的历史位置。点击入口，在旁边打开紧凑记录池；顶部可切换该任务的输出模块，点击记录后面板保持打开。点击外部、关闭按钮、再次点击入口或按 `Esc` 收起。未设置独立封面时，封面记录池为空。

输出模块区域悬停显示「批量应用」，在其菜单内移动时按钮也保持显示：

- **将同名模块设为内容**：作用于当前勾选任务，把其中的同名输出模块设为内容来源。
- **使用同名模块图片作封面**：为当前勾选任务使用同名输出的图片；已有对应批量封面时显示「取消同名模块封面」。

默认勾选全部任务时，批量操作覆盖所有这些任务。记录池模块选项中的批量入口按当前用途同步内容或封面。不同任务各自保留可用的记录，不是将一张图片复制给所有任务。

### 卡片与字段选择

- 点击卡片标题选择卡片；点击字段选择该字段，`Ctrl/Cmd` 加选，`Shift` 按卡片及字段顺序连续选择。
- 点击预览区或卡片内空白取消选择。选中对象会联动定位左侧来源，目标已可见时不滚动；点击左侧工作区或任务区域，也会定位中央对应位置。
- 悬停字段出现两个隐藏按钮：一个只隐藏当前卡片的字段，另一个隐藏当前勾选任务中的所有同名字段。可从左侧重新显示，不删除原始参数。
- 左侧字段的叠层眼睛按钮可批量显示／隐藏同名字段。
- 卡片取得操作焦点后，`← / →` 切换内容历史；视频空格键只操作当前卡片，编辑输入或打开记录池时不穿透操作。

### 版式与字段样式

右侧「卡片布局」设置整行宽度与列数。整行宽度包括卡片和间距；列数变化时，卡片均分同一行的可用宽度。中央居中排列，同一行等高，媒体贴合卡片宽度。

选中字段后才显示「数据样式」，未选字段时连标题和提示一起隐藏。

1. 选择「仅当前字段」或「所有同名字段」（默认），两者互斥。
2. 选择整行、标题 Key 或内容 Value。
3. 设置颜色、字号、文字行距、字段间距，以及加粗、斜体、下划线和删除线。
4. 使用图标切换大小写、对齐方式和行内／块级布局，悬停图标查看含义。

字段间距仅调整当前字段到下一条可见字段的距离，最后一条不生效。块级布局可单独设置 Key 与 Value 的间距，行内布局时该参数不可编辑。大小写转换只影响显示与导出，不改变生成参数。

数据区优先显示内容历史的输入快照；旧记录缺少快照时标注「参数未记录」，不以当前值冒充当时参数。尚无输出的任务显示当前参数，并注明状态。

### 明细表导出

- **PNG**：导出中央当前显示的全部卡片，左侧任务和字段勾选决定范围；无单独的起止编号。默认放大 3 倍，可复制或直接下载一张 PNG。
- **画面**：有独立封面时使用封面；没有时，视频、3D 使用可用当前画面，音频使用波形，保留中文、换行及字段样式。
- **HTML**：打包已勾选任务、内容、封面及字段；「HTML包含全部生成记录」决定是否带入所选输出的全部历史。解压打开 `index.html`，可离线浏览与切换历史。

## 参数表

适合沿用工作区的行列结构、尺寸及样式，选定字段后导出表格。

### 来源与表格

- 左侧「显示任务」「显示字段」分别列出任务和列，每组下方提供全选、取消和数量提示，默认显示有效区域。
- 多工作区时按工作区折叠，任务与字段分两列显示；中央按工作区的列结构横向分区，顶部合并表头显示工作区名。
- 点击工作区合并标题选择整个分区；点击行头、列头或单元格选择局部范围，支持 `Ctrl/Cmd` 加选及 `Shift` 矩形连选。
- 点击顶部模式栏、工作区标签栏或表格空白处取消选择。
- 双击列名称或任务名称改名；拖动边界调整行高、列宽，行列排序沿用表格操作。标题、顺序及外观修改会同步到原工作区。

预览参数表不提供节点绑定、输入／输出类型切换或批量输入取值。这些编辑回到工作区进行；单元格内部的媒体预览仍可操作。

### 单元格设置与历史

右侧「单元格设置」沿用工作区的列宽、行高、矩形比例预览、比例滑杆、内边距及九点对齐。选中单元格、行或列后调整对应范围；多工作区没有指定分区时作用于所有来源。

列宽和行高改变相关整列、整行；内边距、对齐作用于所选单元格。两类设置分别采用最近一次操作的结果，不使用固定的行优先或列优先规则。

输出格右上角显示 `当前条数/总条数`，标签位于媒体右上角，跟随内边距后的媒体位置。选中输出格后，方向键可切换记录，继续沿用输出历史及快照对应关系。

### 参数表导出

- **PNG 放大倍数**：默认 3，支持复制 PNG 或直接下载完整 PNG。
- **下载 Excel**：输出 `.xlsx`，保留可编辑字段、任务和列标题、行列尺寸及多工作区合并标题，将可用图片嵌入对应单元格。视频、音频和 3D 不会变成 Excel 内的完整播放器；Excel 自身的行高、列宽上限仍适用。
- **打包 HTML**：导出当前可见表格与媒体，解压后打开 `index.html`。

PNG 与预览表格的比例、内边距、字体及媒体布局保持对应，列头只显示标题。下载媒体与导出 JSON 是另外的工具，见下方共用导出规则。

## XY 矩阵

适合查看轴参数组合、切换或平铺 Z 层，并按坐标轴布局导出矩阵图。

### 工作区矩阵与来源筛选

已有 XY 工作区时沿用其矩阵，保留每格当前显示的历史。单工作区预览与工作区共用缩放、平移位置，进入预览或切换 Z 层不会重新适配视图。

- **X/Y 取值**：左侧勾选要显示的值，可全选或取消；隐藏的行列在预览中收拢，不删除工作区任务。
- **Z 层**：在画布上点击 Z 取值切层，或在右侧启用「平铺所有 Z 层」。启用后展开列数、行间距、列间距，行列间距同排显示。没有 Z 数据也可预设平铺，之后有值时生效。
- **附加记录参数**：左侧勾选要展示的记录，集中显示在 Z 轴摘要附近的半透明表格，分为节点名称、参数名称、参数值三列。取值来自历史记录，不向生成任务额外注入参数。
- **完整内容**：默认省略长名称、限制值的行数；开启「显示全部内容」后，按各列最大宽度换行，保留全文。勾选及展开状态随工作区保存。
- **当前格子**：仅选中格子时显示，包含任务、输出、历史位置、完整轴值与附加记录；没有保存的参数明确提示。

同一参数组合保留独立历史。平铺时隐藏 Z 轴线及刻度，将唯一的 Z 轴绑定摘要放在公共标题区；每层仍显示 Z 值标题。标题限制在矩阵宽度内，长内容换行并避让绑定摘要。

### 画布、选择与右侧设置

- 左键单击格子选择，左键拖动格子、坐标轴或空白处平移；中键拖动也可平移。滚轮朝指针缩放，媒体控件占用滚轮时可用 `Ctrl＋滚轮` 缩放画布。
- `Ctrl/Cmd` 加选，`Shift` 在同一层内矩形连选；选中输出格后可用方向键切换历史。
- 点击层标题选中该矩阵，标题变蓝，保留平铺状态；点击工作区标题选中该工作区的全部矩阵；点击空白取消选择。
- 右侧分别控制 X/Y/Z 轴与其绑定摘要的可见性；选择 Y 向上或向下，点击 X↔Y、X↔Z、Y↔Z 交换轴。
- 各轴可调整间距、边距、九点对齐原点及 0～360° 文字角度；Z 轴不设置格子间距和边距。查看不清时点击「适配视图」。

有选中矩阵或工作区时，右侧设置作用于该范围；没有选择时，作用于所有预览来源工作区的矩阵。轴设置与工作区共享，筛选不删除任务，视图操作不增加内容撤销步骤。

多工作区各自放在独立纯色矩形区域，外部保留点状背景。工作区标题与 Z 摘要随缩放变化；多来源总览视角独立，不覆盖各工作区原有的单工作区视角。

### 按历史参数重排

没有可用工作区矩阵、界面提供「按历史参数重排」来源时，可选择历史记录中的参数作为 X、Y 及可选 Z，整理已有结果。缺失组合留空，同一组合可保留多条记录；可调整媒体宽度与文字长度。

这是已有结果的显示方式，不会倒推创建生成任务，也不解除参数表与 XY 工作区的结构兼容限制。

### 矩阵导出

设置 PNG 放大倍数后，可复制或直接下载整张 PNG，也可打包 HTML。按中央当前布局导出勾选的 X/Y 范围、当前或平铺的 Z 层及可见坐标轴、标题、摘要；多工作区包含显示中的各分区，而不只是导出媒体缩略图表格。

## 下载、整理与导出

### 下载媒体的范围

五个页面右侧都有「下载全部」「下载选中」，没有可下载的选择时按钮不可用。标题下的说明改为悬停提示。

| 页面 | 下载全部，未包含全部历史 | 下载选中，未包含全部历史 |
| --- | --- | --- |
| 浏览 | 当前来源各组的封面 | 中央当前预览记录 |
| 比较 | 当前来源各组的封面 | A/B 两侧当前记录 |
| 明细表 | 可见卡片的内容媒体 | 选中卡片的内容媒体 |
| 参数表 | 可见输出格当前记录 | 所选行、列、单元格涉及的输出记录 |
| XY 矩阵 | 可见格子的当前记录 | 所选格子的当前记录 |

浏览、比较的复选框名为「含组内全部记录」，另外三个页面为「含所有生成记录」。勾选后扩展到对应来源输出的全部历史，不只下载当前正在显示的记录。

- **打包 ZIP**：下载一个压缩包，里面是独立媒体文件。
- **保存到文件夹**：支持目录访问的浏览器可每批选择一次保存位置；已有同名文件时追加编号。不可用的浏览器将该选项置灰，仍可用 ZIP。
- **文件命名**：使用任务、输出模块、历史编号，例如 `001-002-003.png`，补零以便排序。

下载媒体得到原始文件；复制／下载 PNG 得到排版后的静态整图，两者不同。

### 收集整理与 JSON

- **收集整理**：按当前页面的可见来源，选择是否包含组内全部记录，点击「复制到子文件夹」。可整理的 ComfyUI 媒体复制到 `output/归档目录/工作流名_工作区名`，不移动或删除原媒体。
- **导出 JSON 数据**：选择输入模块、输出模块或输入＋输出模块，可复制或下载。每个任务一个对象，以模块标题为字段名；同名字段追加序号。输出路径在包含历史时使用数组。参数表只导出所选显示任务与字段，明细表采用当前展示的字段值。
- 各导出区的「含组内全部记录」独立生效，不自动改变其他工具的历史范围。悬停标题可查看用途提示。

### PNG 与 HTML

明细表、参数表、XY 矩阵提供版式导出。PNG 放大倍数为 1～10，默认 3；复制到剪贴板需要浏览器允许图片剪贴板访问。

大 PNG 采用分块渲染并逐步压缩为单张图片，不再使用旧的固定总像素阈值提前拒绝。内容量与倍数仍影响耗时、内存和文件大小；浏览器资源不足或单块渲染失败时，降低倍数或通过左侧来源缩小范围。PNG 中的视频、音频、3D 是静态画面或波形。

HTML 包解压后打开 `index.html`，配套媒体、脚本和资源需一并保留。明细表支持带入历史及对应参数，参数表和矩阵保留各自排布。可用媒体支持离线播放或查看，缺少的模型贴图等资源会提示；HTML 不是可运行的 ComfyUI 工作流。

## 保存、撤销与数据维护

- **随工作区保存**：明细表封面、内容、历史位置、字段选择和样式，以及参数表标题与单元格外观、矩阵轴设置等，按所属工作区写入工作流配置；明细表还会在浏览器保存排版偏好作为默认值。删除任务、模块或记录后清理对应失效引用。
- **查看状态**：搜索、筛选、选择、缩放和平移不作为内容编辑入栈；不同查看状态的保存范围不同，不等于所有界面临时状态都永久保存。
- **共享历史**：同一工作区的预览与工作区界面共用内容撤销，工作区之间隔离。当前页面能显示结果则原地撤销，不能显示时自动返回可展示的页面。多来源时以最近操作的工作区或活动工作区为目标。
- **生成结果**：撤销参数或排版不删除后来生成的历史；运行本身不属于可撤销的生成操作。详细规则见 [README：撤销与重做](../../README.md#撤销与重做)。
- **数据维护**：右上角入口管理当前活动工作区，而非所有已添加来源；可以清理失效记录、重新同步媒体和恢复／删除归档任务。删除归档保留磁盘媒体，收集整理也不是恢复归档。
