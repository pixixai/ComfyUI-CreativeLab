## 📅 更新日志

所有关于 CreativeLab (CLab) 的版本迭代、功能优化及修复记录。

### [未发布] - 2026-10-21

- **工作区模式**: 新增“任务卡片、参数表、XY 矩阵”三种工作区模式，底部标签栏左侧向上展开切换菜单。三种模式共享任务、模块、参数绑定与生成历史，各工作区独立保存模式、轴设置及画布视角。
- **参数表**: 按模板展示结构与绑定一致的任务，支持共享结构调整、直接编辑参数、批量填写字段及导入 JSON 对象数组；已有任务保留各自参数值和输出历史，新任务不复制生成记录。
- **独立 XY 矩阵**: 空工作区可直接绑定 X/Y 轴参数与统一输出节点，自动建立参数组合任务。同一轴支持多参数组合，绑定摘要显示节点名称与本地化参数名；绑定面板支持搜索、勾选和拾取节点或参数，拾取后返回原绑定面板。
- **Z 轴分层**: 从 XY 交点向左上方延伸短轴，绑定后按 Z 取值生成多层矩阵，支持单层切换、完整层列表与平铺全部层。默认运行当前层，选择格子后运行选中项，运行菜单可单独执行全部层；各组合独立保留输出历史和参数快照。
- **轴取值与排序**: 文本支持逐行或 JSON 数组，数字支持逗号、换行及 JSON 数组，布尔与固定选项列出完整勾选列表；多参数组合保留类型及组内顺序。“设置取值 / 取值排序”两页支持草稿数量预览、拖拽接缝排序、边缘自动滚动及反向同步输入框，无效输入保留原矩阵；长内容省略显示，悬停查看全文。
- **画布与选择**: 支持 Y 轴向上或向下、朝指针滚轮缩放、空白拖动、中键抓手及按住空格后跟随鼠标平移。Ctrl/Cmd 加选，Shift 按首尾格子围成的矩形范围连选，单击空白取消选择；轴设置面板约束在插件范围内，间距默认 4、边距默认 10。
- **矩阵显示与历史**: 格子生成前默认正方形，媒体加载后按各结果的中位比例统一显示。悬停边缘提亮、选中显示细蓝框，实际运行进度以彩虹描边呈现；右上角显示历史序号，方向键切换所选格子的记录。移除轴取值仅隐藏不匹配任务，切换视图和重新添加相同取值时继续复用已有任务及历史。
- **底部浮动工具栏**: 新增居中胶囊工具栏，依次提供轴向双按钮切换、XYZ 参数与完整取值互换、独立附加记录参数入口、恢复视角及运行。默认标签简化为“运行 · 数量”，选中后显示“运行选中 · 数量”，移除运行按钮左侧分割线及原位置的重复入口。
- **附加记录与文档**: 可单独选择运行时记录的工作流参数，记录随当次历史保存，在矩阵中不额外注入；转换为卡片或参数表时保留为普通绑定输入。更新 README 与局部微创更新重构记录，按模式、画布、轴编辑和任务模型拆分实现文件。
- **测试**: 202 项前端自动测试、121 组浏览器检查通过，覆盖模式转换、空工作区建立矩阵、XYZ 分层与运行范围、取值解析和排序、历史与媒体状态保持、真实鼠标交互及浮动工具栏。

### [v0.9.2] - 2026-10-20

- **明细表工作区**: “结果表”改为“明细表”、“对比”改为“比较”，XY 矩阵独立为顶部功能。明细表按任务排列卡片，默认勾选全部任务，每张卡片选择一个输出及多个输入字段；复用图片、视频、音频、文本与 3D 组件，历史切换同步展示对应参数快照。
- **卡片排版与字段样式**: 支持整行宽度、列数、居中及同排等高布局，媒体铺满卡片宽度。字段支持 Ctrl/Cmd 加选、Shift 连选及空白取消选择，可按当前字段或所有同名字段调整 Key/Value 的颜色、字号、字形、大小写、对齐、行距、字段间距、行内或块级布局及块级标题间距。
- **来源与字段管理**: 来源区可单独显示或隐藏字段，通过“眼睛＋叠层”按钮批量切换同名字段；卡片字段提供局部隐藏与同名隐藏入口。选择卡片或字段时自动定位对应来源，仅在目标不可见时滚动，保留勾选状态与媒体。输出支持按名称批量切换预览或设置封面。
- **独立封面与记录池**: 封面与普通预览分别保存模块和历史位置，悬停播放内容，移开暂停并恢复封面。卡片右上角提供两个紧凑记录池，选择记录后保持打开，支持连续选择、切换模块及批量应用；未设置封面时封面记录池为空。已批量应用的同名封面可直接通过“取消所有任务封面”清除，保留普通预览。
- **PNG 与离线 HTML**: 明细表可按当前布局将全部卡片或指定编号范围复制、下载为一张 PNG，默认放大 3 倍，完整保留所有行、中文、字段样式及媒体静态画面。HTML ZIP 包含所选字段、历史、封面及配套媒体，复用本地播放器和 3D 查看器，脱离 ComfyUI 服务后仍可浏览历史与播放媒体。
- **交互与性能修复**: 修复来源图标点击后因焦点残留而无法自动隐藏，以及同名输出批量操作继续沿用旧选择的问题；发起任务准确使用点击的模块，其余任务按名称匹配。记录池选中框、历史入口及字段调整原位更新，复用未切换的播放器；封面按可见范围加载，3D 截图串行执行并释放临时资源。输入历史快照补充未绑定的备注字段，制表和样式调整不改写工作区数据。
- **文档与测试**: 更新 README、局部微创更新重构记录及依赖说明；153 项前端测试、90 项浏览器检查通过，覆盖字段多选与批量操作、独立封面、记录池连续选择、真实媒体交互、完整 PNG 与离线 HTML 导出及资源释放。

### [v0.9.1] - 2026-10-19

- **对比布局**: 对比模式与浏览模式共用左侧来源树和底部缩略图带，支持来源筛选、区域调整、收起恢复及自定义排序；缩略图可拖入指定 A/B 区域，单击添加或替换后自动切换待选区域。
- **悬浮界面**: A/B 媒体信息移至预览区两侧顶部，使用正方形编号标记待选区域，缩略图同步显示 A/B 标记；布局切换胶囊悬浮于底部，媒体可铺满预览区，移除悬浮控件投影。
- **交换入口**: 分割线中间改为空心圆与实心双向箭头，圆的上下描边连接分割线；分屏时随分界线移动，悬停时保持位置，箭头与圆环渐变为白色、圆环略微加粗，保留透明点击范围。
- **统一视频组件**: 浏览、对比预览复用模块内的视频控制条，支持单击画面或空格播放 / 暂停、滚轮调节进度、点击底部进度条跳转，以及音量、倍速、画中画和全屏；自动播放遵循已有设置，编辑输入框时空格不触发播放。
- **视频缩放与同步**: 新增 `Ctrl＋滚轮` 朝鼠标位置缩放，中键拖动平移，与滚轮寻道独立；A/B 视频同步播放、进度及倍速，以共同有效时长为范围，声音可选 A、B 或静音。
- **状态与资源保护**: 切换对比布局、待选区域和来源筛选时复用未更换的媒体，交换视频保留进度与播放状态；修复首次缓冲时播放启动被中断的问题，切换预览或关闭窗口时清理菜单、事件、定时器及媒体资源。
- **文档与测试**: 更新 README 与局部微创更新重构记录；126 项前端测试、64 项浏览器检查通过，覆盖真实视频播放、指针位置缩放、原生鼠标与空格交互、A/B 拖放、状态保持及资源释放。

### [v0.9.0] - 2026-10-19

- **预览工作区**: 新增“浏览、对比、结果表”三种模式，支持同一卡片或跨卡片的多个输出模块共同预览；可从模块、任务卡片标题或空白处的右键菜单进入，默认勾选所选来源。
- **来源与区域布局**: 浏览模式采用左侧来源、中间预览、右侧参数、底部缩略图布局。来源使用任务及模块的实际标题，支持搜索、整组勾选与半选；点击任务名称勾选，左侧三角单独控制折叠。左右面板及底部区域均可拖动调整大小，继续拖过最小尺寸可收起，点击边缘三角恢复默认尺寸。
- **缩略图浏览**: 默认按输出模块分区，支持媒体类型筛选、生成顺序与自定义排序、普通滚轮横向浏览，以及单条、多选和整个分区的接缝拖拽排序。工具栏集中显示筛选数量、当前来源和记录位置，最右侧提供缩略图大小滑杆及恢复图标，滚动条收窄至 6px。自定义排序仅改变预览列表，保留原始历史和参数关联。
- **图片与视频 A/B 对比**: 支持跨模块选取两张图片或两个视频，以并排或分屏方式比较；分屏随鼠标移动分界线，图片同步缩放和平移，视频共用播放、进度、倍速及滚轮调节，并可选择 A、B 或静音。
- **生成结果表**: 根据历史运行编号和参数快照生成明细表，支持选择记录、调整输出列与参数列。新增 XY 参数矩阵及 Z 参数分组，整理已有结果中的组合，保留重复结果和缺失组合，不额外创建或运行任务。
- **表格导出**: 支持分页 PNG 及包含媒体文件的 HTML ZIP，离线打开查看图片、播放视频和展开文字；使用本地 ZIP 依赖，导出时提示缺失资源。
- **参数与性能保护**: 普通浏览保留历史关联切换和参数回填；A/B 选样、制表和排序不改写当前输入参数或模块历史。来源搜索、区域调整、收起及排序时复用未切换的中央预览，保留视频播放状态和 3D 视角，视频缩略图按横向可见范围加载，关闭时清理资源。
- **文档与测试**: 更新 README、局部微创更新重构记录及依赖说明；123 项前端测试、59 项浏览器检查通过，覆盖多来源筛选、真实拖拽与区域收起恢复、媒体状态保持、A/B 对比、XY/XYZ 矩阵及离线导出。

### [v0.8.2] - 2026-10-19

- **输出外观**: 统一输出模块标题、悬停操作入口及底部信息栏，图片和视频显示实际分辨率，音频显示格式与时长；多条历史记录时在右下角显示各自序号，保留原有历史关联规则。
- **播放交互**: 音频改为单击波形播放或暂停，视频通过单击画面播放或暂停，移除各自独立播放按钮；音频新增滚轮调节进度，结束后恢复原先播放状态，优化视频控件及文本选项的对齐。自动播放视频默认关闭，保留已保存的个人设置。
- **音频性能**: 按可见范围读取真实波形并缓存，模块与独立预览共用波形数据；保留暂停状态和播放器元素，移除时清理监听、菜单和播放资源。
- **3D 格式与动作**: 支持 GLB/glTF、FBX、OBJ/MTL、STL、普通 PLY 网格与点云，以及 BVH 骨架预览；支持 GLB/glTF、FBX 和 BVH 动画的播放、暂停、片段与速度选择及底部进度条。新加载动画默认暂停，不受视频自动播放设置控制。
- **3D 预览交互**: 输出模块运行后直接在模块内预览，仅通过右键“预览模式”打开独立窗口；输入模块勾选“查看 3D”后显示。预览区内左键拖动旋转，中键或右键拖动平移，滚轮缩放，`Shift＋滚轮` 调节动画进度；预览区外仍可拖动模块。
- **3D 修复与性能**: 修复输出模块选中后再次拖动变成移动模块的问题；输入、输出预览区统一为 200px 高度和相同左右边距，贴图提示自动换行。相同模型局部更新时保留画布与播放状态，静止或暂停时停止持续绘制，隐藏或关闭时释放渲染资源。
- **输出抓取与归档**: 兼容原生“加载 3D”参数、标准 3D 文件列表及旧版预览节点返回，修复文件子目录解析和误显示尺寸文字的问题；归档 GLB/glTF、OBJ 和 FBX 时保留已找到的外置缓冲、材质与贴图及相对目录，沿用运行编号和历史关联。
- **上传预览**: 图片、视频、音频及 3D 上传模块在标题旁增加预览开关，默认关闭并按模块保存；收起时仅保留文件选项、上传和清除按钮，仍支持拖拽与粘贴上传。关闭媒体预览时停止播放并释放相关资源。
- **文档与测试**: 更新 README、局部微创更新重构记录及依赖许可说明；105 项前端测试、16 项后端测试及 48 项浏览器检查通过，覆盖多格式模型、动画、连续旋转、提示布局、历史切换和资源清理。
