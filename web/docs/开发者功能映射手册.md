# 开发者功能映射手册

本文对应 v1.0.2，用于从界面功能定位代码。所有路径相对仓库根目录；当前架构边界见 [开发指南](开发指南.md)，分阶段变更见 [重构记录](局部微创更新重构记录.md)。

## 入口与持久化

| 功能 | 主要文件 |
| --- | --- |
| ComfyUI 注册与初始化 | `web/main.js`、`__init__.py` |
| 面板创建、显示和渲染编排 | `web/ui_panel.js`、`web/components/events/event_panel.js` |
| 工作区状态、schema v4 与旧通道迁移 | `web/components/ui_state.js` |

| 工作区默认值和缓存预算 | `web/components/workspace_preferences.js`、`web/components/cache_preferences.js` |

## 三种工作区

| 模式 | 核心入口 | 关键模型与交互 |
| --- | --- | --- |
| 任务卡片 | `comp_taskcard.js`、`comp_modulearea.js`、`workspace_modes/mode_cards.js` | `ui_selection.js`、`workspace_modes/card_window.js`、`workspace_modes/card_layout.js` |
| 参数表 | `workspace_modes/mode_table.js`、`workspace_modes/table_view.js` | `table_sheet.js`、`table_model.js`、`table_selection.js`、`table_editing.js`、`table_gestures.js`、`table_binding.js`、`table_cell_panel.js`（均在 `workspace_modes/`） |
| XY 矩阵 | `workspace_modes/xy_controller.js`、`workspace_modes/mode_xy.js` | `xy_model.js`、`task_model.js`、`xy_binding.js`、`xy_values.js`、`xy_axes.js`、`xy_canvas.js`、`xy_gestures.js`、`xy_layers.js`（均在 `workspace_modes/`） |
| Z 层平铺、轴交换与附加记录 | `workspace_modes/xy_tiling.js`、`xy_axis_swap.js`、`xy_records.js`（后两项也在 `workspace_modes/`） | `xy_axis_panel.js`、`task_records.js`（分别在 `workspace_modes/`、`actions/`） |

参数表和矩阵的列、轴是配置入口，不是 DOM 索引。任务、模块和单元格的选择、排序、回填与归档都使用稳定 ID。

## 拾取与绑定

- `actions/action_binding.js`：工作流命中解析、节点／参数拾取、Primitive 下游映射、共用中键手势。
- `modules/module_binding.js`：卡片摘要、多节点参数面板、模块中键拾取。
- `workspace_modes/table_binding.js`：整列绑定，保留各行值与生成历史。
- `workspace_modes/xy_binding.js`：轴、输出及附加记录绑定，复用轴换绑、归档规则。
- `workspace_modes/xy_rebind.js`：同类型换绑、组合分量映射、取值及原输入格式保留。

## 运行与历史

执行链为「模式范围 → 循环次数 → 点击时快照 → 有界提交 → prompt ID 映射 → 资产归档 → 结果回写」。

| 功能 | 主要入口 |
| --- | --- |
| 卡片范围、次数及共用打断按钮 | `actions/action_run_executor.js` |
| 提交窗口、任务核对与定向取消 | `actions/execution_queue.js`、`web/api_injector.js` |
| 运行进度 | `events/event_execution.js`、`web/api_injector.js` |
| 彩虹反馈 | `comp_taskcard.js`、`workspace_modes/table_activity.js`、`xy_activity.js`、`progress_outline.js`（后两项也在 `workspace_modes/`） |
| 运行任务自动定位 | `workspace_modes/workspace_follow.js` |
| 输出历史、参数快照与关联运行 | `modules/media_types/media_utils.js`、`modules/module_history.js` |
| 记录网格与批量移除 | `modules/module_output.js` |
| 任务归档与恢复 | `workspace_modes/task_archive.js`、`xy_archive.js` |
| 工作区复制与运行状态隔离 | `workspace_copy.js` |

数组维护不得只改媒体 URL；文本、快照、运行元数据及当前索引必须保持对应。结果回传不依赖当前活动工作区。

## 撤销、资源与性能

- 内容历史：`edit_history.js`、`edit_history_runtime.js`、`history_snapshot.js`、`history_context.js`、`history_tasks.js`。
- 模块回收：`modules/module_lifecycle.js`；媒体渲染器在 `modules/media_types/`，模型查看器为 `media_model.js`。
- 卡片窗口与分帧加载：`workspace_modes/card_window.js`、`viewport_components.js`，以及 `frame_work.js`、`panel_loading.js`。
- 缓存与布局结果：`workspace_modes/card_cache.js`、`card_layout.js`、`media_dimensions.js`，以及 `modules/input_measure.js`。
- 卡片滚轮与刻度跳转：`events/card_wheel.js`、`workspace_modes/task_ruler.js`、`card_navigation.js`、`card_navigation_plan.js`（后两项也在 `workspace_modes/`）。

历史记录按工作区隔离；查看不入栈，内容编辑需标明所属工作区。临时 DOM、播放器、撤销队列不能写进持久化配置。
