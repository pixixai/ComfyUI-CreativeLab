# Creative Lab (CLab) 局部微创更新重构记录

本文记录从整页重建到按变化更新的演进，以及当前渲染、保存和资源释放的边界。第二阶段更新日期：2026-10-18。

## 一、重构背景与第一阶段

早期的 `saveAndRender()` 同时保存状态并重建整个卡片列表。修改参数、移动模块或刷新输出时，无关模块也会重新生成 DOM。视频、音频随父节点销毁后，可能重新加载、暂停或丢失播放位置；输入焦点与滚动位置也容易受影响。

第一阶段将多数操作改为局部处理：

- `surgicallyUpdateArea(areaId)` 只更新目标模块。
- 模块和卡片排序直接移动现有 DOM。
- 必须重建模块时，使用隐藏的 `#clab-mini-vault` 暂存原有音视频元素，再根据资源地址恢复。
- 工具栏独立刷新，输入、历史切换和执行结果不再普遍触发整页重建。

这些改动解决了主要的全局闪动问题。剩余开销集中在模块内部重建、重复绑定监听、逐帧扫描播放器，以及频繁序列化全部工作区数据。

## 二、当前架构：按变化更新

### 更新层级

| 变化 | 当前处理 | 保留内容 |
|---|---|---|
| 选择状态、绑定摘要、标题 | 更新对应的类名、文字、属性 | 模块主体和媒体元素 |
| 输出比例、宽高、填充方式 | 更新预览容器和媒体样式 | 播放器、播放位置、暂停状态 |
| 相同类型媒体的历史切换 | 更新现有媒体的 `src` 和历史序号 | 模块外壳、播放器控件；新资源按自身加载规则播放 |
| 文本历史或显示选项变化 | 更新正文、复选框、历史序号；相同正文与模式复用渲染结果 | 文本外壳及选项控件；同一记录保留滚动位置 |
| 历史缩略图选择 | 更新选中边框和覆盖层 | 已加载的缩略图及网格滚动位置 |
| 模块或卡片移动 | 按状态顺序移动现有 DOM，跳过已有正确位置 | 控件状态；支持时使用浏览器的 `moveBefore()` 保持连接状态 |
| 输入控件类型、输出预览/管理模式变化 | 重建对应模块或内容区域 | 同一资源的音视频通过暂存机制尽量恢复 |
| 重新打开面板 | 核对卡片、模块 ID 与顺序，结构一致时原位刷新 | 已有卡片、模块、焦点和滚动位置 |
| 结构无法原位复用 | 重建列表，并恢复匹配的音视频 | 保留原有重建兜底路径 |

这里的“局部更新”指减少 DOM 拆建。尺寸、位置或画面变化仍可能触发布局和绘制，不代表浏览器完全不重绘。

### 更新入口与职责

- **`comp_modulearea.js`**
  - `surgicallyUpdateArea(areaId)`：同步更新入口，先调用输入或输出模块的原位更新方法；结构不兼容时才重建模块。
  - `scheduleAreaUpdate(areaId)`：将执行结果和媒体尺寸变化合并到下一帧，同一模块 ID 在一帧内只刷新一次。
  - `justSave()`：立即持久化，不触发渲染。
- **`module_input.js`**
  - `refreshInputAreaInPlace()` 更新文本框、布尔值、下拉菜单及上传区域。
  - 相同资源的上传媒体保留原元素；文本框保留焦点，按需要重新计算高度。
- **`module_output.js`**
  - `refreshOutputAreaInPlace()` 分别更新预览样式、资源地址、绑定摘要、复制入口、文本和历史管理网格。
  - 尺寸、绑定或相同类型的资源变化不再拆除整个输出模块。
- **`ui_panel.js`**
  - 负责面板与工具栏组合，检查已渲染卡片/模块的 ID 和顺序后决定复用或重建。
  - 普通重新打开走复用路径，不把所有媒体搬进暂存区。

现有 `window._clabSurgicallyUpdateArea`、`window._clabScheduleAreaUpdate` 等桥接入口继续供动作层调用。更新逻辑由对应模块负责，动作层只提交需要更新的模块 ID。

## 三、媒体播放与进度更新

### 按需更新播放器控件

`module_media.js` 管理播放器登记、可见范围与动画帧调度：

1. 播放器首次绑定时登记，并监听其可见范围。
2. `play`、`pause`、`seeked`、`volumechange`、`loadeddata` 等媒体事件更新对应播放器。
3. 只有面板可见、页面可见、播放器进入可见范围且正在播放时，才加入动画帧更新集合。
4. 集合为空时取消动画帧；关闭面板或切换到后台页面时停止进度控件刷新。

隐藏面板只停止控件轮询，不主动改变主播放器的播放/暂停状态。时间文字仅在显示内容变化时写入，减少重复 DOM 写操作。

### 重建时的媒体暂存

结构变化仍可能使用媒体暂存。恢复时比较完整的规范化 URL，保留 `filename`、`subfolder`、`type`、缓存刷新参数等区别，避免把不同目录中的同名文件当成同一资源。URL 片段不参与暂存匹配。

原位更新优先保持媒体与父容器的连接。浏览器不支持 `moveBefore()` 时，移动操作通过 `insertBefore()` 完成，并恢复此前正在播放的媒体。

## 四、状态修改与持久化分离

运行时状态在输入事件中立即更新。合并保存只延后写入配置节点，不延后参数值本身。

- 连续输入、普通选择调用 `scheduleSyncToNode()`，在 250ms 的窗口内合并写入。
- 输入提交、绑定、结构调整等原有立即保存操作继续调用 `syncToNode()`。
- 运行任务前和工作流序列化前，通过 `flushPendingSave()` 写回尚未保存的数据；页面退出时也尝试写回。
- 立即保存会取消待执行的保存回调，避免随后重复序列化。
- 加载其他工作流时取消旧的待保存回调，防止旧状态覆盖新工作流。
- 一次保存只执行一遍活动工作区同步，再整理并序列化全部工作区数据。

完整序列化仍服务于现有配置锚点和工作流格式，未引入新的持久化格式。

## 五、监听器和临时资源生命周期

`module_lifecycle.js` 为模块资源提供统一的移除清理入口：

- `onModuleRemoved(element, cleanup)` 登记该元素拥有的清理操作。
- 面板内使用一个 `MutationObserver` 观察移除；回调时检查元素是否仍连接在文档中。
- 同步移动到其他卡片的元素仍连接在文档中，保留资源；真正删除或替换的元素执行清理。

各组件负责释放自身资源：

- 输入文本框仅绑定一次尺寸监听，移除时断开监听、取消高度计算的定时器与动画帧。
- 文本输出取消共享 `ResizeObserver` 对旧外壳的观察；只在宽度变化时响应尺寸监听，避免高度调整反馈循环。
- 上传区仅在文件输入控件或上传类型变化时重新绑定，移除后清理全局上传处理表。
- 音视频播放器退出登记和可见范围监听，移除后停止已脱离界面的播放。
- 历史缩略图取消观察；移除的视频缩略图释放媒体地址。
- 文本渲染缓存以模块对象为弱引用键，仅保存该模块最近一次正文及显示模式的结果。

上传预览与文件操作行独立更新：关闭预览时移除媒体，保留文件选择、上传和清除控件；开关按模块持久化。音频波形仅在可见时读取并缓存，关闭或移除播放器时取消监听、滚轮调节定时器和脱离界面的播放。

3D 查看器按需加载本地 Three.js，统一支持 GLB/glTF、FBX、OBJ/MTL、STL、普通 PLY 及 BVH 骨架。输入区通过预览开关启用，输出区直接内嵌预览，模型地址不变时保留画布、视角和播放状态，地址变化时清理旧查看器；独立窗口仅通过右键“预览模式”进入。`model_loader.js` 负责格式解析和配套资源地址，将模型中的相对路径映射到 ComfyUI 的文件接口；归档时仅复制模型声明且本地存在的配套文件，隔离存放并保留原目录关系。

静态预览和暂停动画仅在加载、视角、播放进度或尺寸变化时绘制；仅正在播放且可见的动画持续逐帧更新。视角在预览区内通过左键旋转、中键或右键平移、滚轮缩放，阻止预览区触发模块拖拽；右键单击保留菜单，右键拖动不弹菜单。动画使用底部进度条和 Shift＋滚轮调节，模块运行时保存位置、片段、速度和播放状态。暂时隐藏后释放模型几何、材质、贴图、动画混合器、Blob 地址、WebGL 上下文、尺寸监听和拖动/滚轮续播处理器，重新显示时从运行时状态恢复。独立预览窗口在关闭或切换历史前显式清理，历史仍按运行编号关联。

## 六、执行结果合并与任务清理

一次输出节点回传可能同时更新多个输出模块，当前流程为：

1. 根据任务快照定位原工作区、卡片与参与输出模块。
2. 增加该任务正在处理的结果数，异步完成资产归档和历史写入。
3. 收集变更模块；同一回传内只持久化一次，再按模块 ID 调度界面更新。
4. 媒体真实尺寸由已显示的预览元素加载事件提供，更新比例并调度原位刷新；不再额外创建探测图片/视频，再重建一次播放器。
5. 收到完成、失败、中断或成功删除队列任务的通知后，标记任务结束。
6. 结束且没有正在处理的异步结果时，移除任务映射及批次中的运行 ID。

运行结束通知可能早于资产复制完成，因此任务清理必须等待异步结果全部处理完。完成事件早于提交 HTTP 响应时，也不会在响应返回后重新留下已结束任务。

历史中的运行编号、参数快照和参与模块列表属于持久数据，不随临时任务清理删除。单独运行输出模块、部分运行、后台工作区回传及历史关联仍采用原有规则。

## 七、历史缩略图加载

- 网格先创建缩略图占位元素，资源地址保存在 `data-clab-src`，进入可见范围附近后才赋给 `src`。
- 图片保留浏览器懒加载提示；视频高性能模式保留 `preload="metadata"`，该属性是加载提示，不能保证仅下载一帧。
- 动态视频缩略图离开可见范围或面板隐藏时暂停，重新进入时按动态预览模式恢复播放。
- 选择缩略图时保留已加载元素；历史增删、排序或缩略图显示内容变化时更新对应网格。
- 历史条目本身仍全部保存在内存和原有工作流数据中，懒加载针对预览资源，不裁剪用户记录。

### 预览模式的多来源记录、明细卡片与 XY 矩阵

`preview_records.js` 将所选输出模块的历史转换为带来源、运行编号和参数快照的预览记录，保留原历史索引，不修改工作区状态。普通浏览仍通过 `selectOutputHistory` 执行历史关联与参数回填；A/B 选样、任务卡片与字段勾选、历史位置、坐标轴及筛选保存于预览窗口会话；明细表排版与字段样式单独保存为浏览器本地偏好。

`preview_browse.js` 管理左侧来源树、区域分割线及底部缩略图带。来源目录使用卡片、模块的实际标题，任务名称点击勾选，箭头单独控制折叠。左右宽度及底部高度只更新 CSS 布局变量；拖过最小尺寸后将相应尺寸置零以收起区域，保留分割线上的三角按钮，点击恢复默认尺寸，区域 DOM 和当前媒体均复用。缩略图默认按模块分区，支持滚轮横移、记录多选、接缝插入和整区拖拽；自定义顺序以稳定记录键保存在预览状态，不改写模块历史、运行标记或输入参数快照。视频缩略图进入横向可见范围后才读取媒体。排序、来源变化后若当前记录仍在则复用中央预览，避免播放器或 3D 查看器被无关重绘打断。关闭预览时释放缩略图监听和媒体地址。

浏览与比较共用 `preview_browse.js` 的来源树、区域分割线及底部缩略图。拖拽通过当前窗口的稳定记录键指定 A/B，单击缩略图后自动切换待替换区域，不调用历史回填。缩略图内部排序仍由预览列表管理，拖入媒体区只更新对比选样。

`preview_compare.js` 负责覆盖在媒体上层的 A/B 信息、分割线交换按钮、布局切换、双图视角及两路视频同步。A/B 信息无外框，仅点亮待替换区域的编号；布局切换悬浮于媒体底部，不预留额外高度。相同媒体对的区域选择、来源筛选与布局调整复用现有元素，仅同步控件和分割位置；更换媒体对时才清理并重建。交换视频时依据无序的媒体对身份保留进度与播放状态。暂停时不持续申请动画帧；切换模式或关闭窗口时中止事件监听、定时器和媒体播放。`preview_video.js` 为浏览与比较共用播放器行为；控制条标记、进度、音量和倍速菜单复用模块内 `media_video.js`，对比仅增加声音来源选择。视频的滚轮寻道与 Ctrl＋滚轮指针缩放分开，空格播放不占用输入框；同步视频以共同有效时长播放，清理时释放弹出菜单、事件、定时器、动画帧和媒体地址。`preview_table.js` 专门按快照中的节点与参数绑定建立 XY/XYZ 分组，缺失组合和重复组合分别保留，XY 矩阵作为独立顶部功能。四种模式共用来源区域的分割线与收起恢复逻辑，明细表与 XY 不显示底部缩略图带。

`preview_detail_model.js` 按任务生成卡片模型，每个任务只选择一个输出，以稳定历史键定位记录；输入数据直接按模块快照组织，不将多节点绑定展开成重复字段。缺少快照明确标记，尚无结果时使用并标注当前值。新记录的输入快照包含未绑定参数的备注字段。格式与大小写仅在呈现层应用，保留原数据。字段行高与后续间距保存在行样式中；间距按当前可见字段顺序计算，最后一条不产生尾部间距，块级 Key/Value 间距独立保存并仅在块级布局中渲染，在线、PNG、离线 HTML 共用同一字段标记。

`preview_detail.js` 管理来源、字段选择、右侧样式与布局，来源默认选中全部任务。输入字段的普通勾选按卡片保存；悬停“眼睛＋叠层”按钮按来源名称聚合当前勾选任务的字段，以稳定字段 ID 批量修改各卡片的输入显示集合，兼容同名的多个模块及历史字段；按钮与勾选标签分开，字段显示切换原位更新来源区的复选框和图标，保留按钮、焦点与悬停状态；预览仅更新字段区域，保留媒体。输出行使用“叠层＋箭头”批量菜单，分别应用普通预览或封面，按来源标题（未命名时按默认序号）匹配当前勾选任务；每卡片仍单选，无同名输出时保持原状，有多个同名输出时优先保留已选项。批量切换只修改预览会话的输出映射，复用各输出已有历史位置；来源单选框与图标原位同步，未切换媒体继续复用。在线字段宿主附加局部隐藏与同名隐藏按钮，沿用输入显示集合，不改写任务数据；隐藏会剔除受影响字段的选择，保留其他选择和媒体。预览选择同步来源行高亮，显式点击时展开任务，目标已在视野中则不滚动，越界时按行中心滚动到面板中央并由原生滚动边界限制位置；来源搜索挡住目标时先清除搜索。卡片标题支持只选中卡片，空白仍取消选择。PNG 克隆移除字段操作入口，离线页面不附加这些在线控件。宽度保存为包含间距的 `rowWidth`，列数变化仅均分剩余空间；在线、PNG 和离线 HTML 共用居中、同排等高的 Grid 样式。字段多选使用卡片与字段 ID 组成的稳定键，支持 Ctrl/Cmd 加选与 Shift 跨卡片连选；范围默认为同名字段，也可仅修改选中字段。每张卡片保留独立媒体宿主，只有媒体记录更换时才释放并重建该宿主；列数、宽度、字段样式和侧栏调整均原位复用媒体。`preview_detail_pool.js` 管理两个角色的锚点记录池、模块选择与按角色批量应用，面板紧贴入口、按可用空间翻转与限制尺寸，点击外部关闭；未设置封面时不继承预览记录，缩略视频按可见性加载，关闭时释放媒体；Esc 只关闭记录池，不影响外层预览。来源圆形标记分别反映当前预览与独立封面，可同时点亮两行；点击封面行只移除封面映射，保留预览来源。封面以卡片 ID、输出 ID 与稳定记录键保存在预览会话的 `covers` 映射，不修改工作区历史或参数；普通输出继续使用原有输出映射与独立历史位置。`preview_detail_cover.js` 在原媒体宿主上附加静态封面，悬停播放与移出暂停复用原播放器，封面更新不重建内容。封面按可见性准备，3D 截图串行执行并及时释放临时渲染器，切换封面中止未完成截图；PNG 主动准备范围内的离屏封面，离线 HTML 收集封面资源并复用同一覆盖层。`preview_detail_media.js` 为在线和离线明细复用视频、音频、文本和 3D 组件；图片和视频读取媒体宽高比适配卡片，文本控件通过局部解析与刷新回调操作副本，不回写工作区。空格播放限定当前卡片，移除时中止监听、计时器、波形观察和 3D 渲染。

`preview_detail_export.js` 导出整张 PNG 时按当前预览顺序截取起止编号范围、冻结媒体画面并复制已选字段样式，使用 UTF-8 SVG/foreignObject 按浏览器排版栅格化，按设置倍数输出（默认 3 倍），范围内卡片按当前列数和整行宽度重新排列，测量完整内容高度后生成一张图，复制与下载使用同一路径；尺寸超限时明确报错，不自动裁切或分页。已载入的 3D 使用当前镜头，未载入时通过相同查看器临时渲染并释放。HTML 只封装所选字段及相应历史，媒体转为本地数据脚本，包含模型外置缓冲、材质和贴图，缺失资源单独提示。`preview_detail_offline.js` 构建为本地 `vendor/detail-viewer.js`，通过资源读取与路径解析适配器复用查看器，不依赖原服务或远端脚本。

`preview_export.js` 保留 XY 矩阵的分页 PNG 和 HTML ZIP 导出。ZIP 使用本地 fflate 子集；所有导出均不创建执行任务，不修改已有历史的存储格式。

### 工作区的三种编辑视图

`workspace_modes/` 将模式协调、任务卡片、参数表、XY 布局、轴设置、参数选择、画布交互与纯任务模型分别拆分。`ui_panel.js` 只在正常刷新完成后通知模式控制器；底部模式按钮独立于顶部工具栏，XY 模式隐藏工具栏后仍可切换。

工作区的 `view` 保存模式、模板 ID、矩阵任务成员 ID、轴绑定与有序取值、Z 当前层与显示方式、附加记录参数和缩放平移。三种视图直接引用原 `cards/areas`，轴使用稳定节点与参数键，不依赖显示标题或模块位置；自由卡片中修改已入组任务的模块标题、顺序或增补字段后，矩阵仍按成员 ID 保留任务，再按实际参数定位格子。配置经原工作区保存链路序列化，通道绑定仍由原通道逻辑管理。

`mode_cards.js` 恢复自由卡片；`mode_table.js` 按结构和绑定选择同组任务，编辑实际输入模块。`table_structure.js` 记录组内模块 ID 与原位置，传播结构及绑定变化时保留各任务原有模块 ID、参数值和生成记录。批量值按行赋予，JSON 对象数组按任务导入，不自动交叉组合。

`xy_controller.js` 管理独立矩阵操作，空工作区可直接绑定两轴和输出节点，不需要卡片模板。`xy_model.js` 负责从已有卡片推导初始轴、自动补齐组合、统一输出绑定与附加记录输入；轴增减绑定时按原坐标更新现有任务，保留身份和历史。输出模块通过稳定 ID 定位，卡片中的标题、顺序不影响矩阵成员。左侧不再控制生成宽高，旧任务中已有的宽高输入保留为普通绑定输入。

`mode_xy.js` 原位定位已有卡片，隐藏普通卡片外壳与输入区。`xy_axes.js` 在媒体变换层之外绘制可编辑轴线、刻度和绑定摘要，平移缩放时投影坐标并按实际字号重新绘制，避免放大缓存图层造成文字和边框模糊；统一输出入口位于与坐标轴直角相对的角的右侧。`xy_binding.js` 复用模块绑定面板样式，`xy_values.js` 管理轴设置与单轴、成组取值；间距、边距按轴保存，选项即时应用，文本在 change 或 Ctrl/Cmd+Enter 时验证并应用，无效值不更改原数据。刻度面板使用稳定轴名与索引重新寻找锚点，布局变化后不因旧刻度 DOM 移除而关闭。`xy_popover.js` 负责锚点面板定位与清理，`xy_settings.js` 生成绑定摘要及底部工具栏，`xy_styles.js` 保存矩阵样式。

矩阵单元格默认间距 4、边距 10，按轴独立调整；设置面板将间距和边距放在同一行，单参数只显示一次参数名称，多参数选择列表保留分组名称。轴设置使用插件面板与浏览器可视范围的交集作为边界，空间不足时向内偏移、限制尺寸并滚动；ResizeObserver 同步面板与弹出层尺寸变化，关闭时断开观察。清除卡片内边距、圆角与参数注释，隐藏输出底部信息及占位提示。悬停框、选中蓝框独立绘制在格子顶层，避免模块主题边框覆盖。同一坐标只显示并运行一张任务，优先沿用已有结果；重复任务及历史保留在原数据中，不为它们额外扩展矩阵行。未生成任务的占位框原位复用，空白单击同时清除任务与占位框选择。`xy_layout.js` 对已加载媒体的真实比例排序，取中位图像的比例（偶数取较小中项），没有媒体时为 1:1；显示比例不注入生成参数。`xy_selection.js` 接管矩阵选择，Ctrl/Cmd 切换单格，Shift 按坐标矩形连选，复用现有选择 UI 和运行队列。`xy_history.js` 复用输出模块原历史与切换链路，补齐只有当前 URL 的旧记录、恢复缺失的历史索引，在格子右上角直接显示无背景历史计数；方向键可对所选各格分别切换。模式转换仍使用同一任务与输出对象，不克隆或清空历史。

API 注入器持有实际运行任务集合，通过 `getRunningCardIds(workspaceId)`、`getRunningCardProgress(workspaceId)` 和 `clab_task_activity` 提供按工作区隔离的状态与进度。节点汇总及步进事件沿用进度条百分比，不按时间伪造进度；同一卡片有多个运行任务时取尚在运行任务的较小进度。`xy_activity.js` 在格子上原位维护 SVG 彩虹进度框，以真实矩形尺寸和 `pathLength=100` 控制描边长度，进度间仅做短过渡，不循环自转、不重建媒体或轮询面板；选中描边缩为 1px。完成、失败、中断及提前结束均在任务释放路径清除状态；模式切换后恢复仍在运行的格子及进度。

轴刻度按钮按文字内容收紧，Y 刻度使用文本高度并定位到单元格中心，不再把整行的透明矩形作为点击区。`xy_canvas.js` 在捕获阶段处理空白左键拖动、中键跨轴拖动和空格无按键跟随，避免轴设置、媒体控件或模块中键拾取抢走手势。空格只在画布上且未编辑输入框时生效，释放空格、失焦、隐藏页面及退出矩阵均清理抓手状态；拖动后的点击不打开轴面板。轴设置同级行采用统一 8px 间隔，选项行缩为 24px，间距与边距标签紧跟输入框。

`parameters.js` 读取 ComfyUI 的节点名称、控件显示标签及布尔、枚举选项；显示名称不改变绑定标识。取值面板通过复选框维护带类型的轴值，多参数仍保留有序组合。取值面板锚定实际点击的轴线或刻度，X 轴按方向在外侧上下展开，Y 轴在左侧展开，并按可用空间约束尺寸与滚动。

左侧记录项仅在控件内容改变时局部替换，按钮焦点不阻止记录项增删的即时反馈。Y 轴刻度右对齐，两轴刻度文字采用相同的轴外留白。绑定摘要按显示名称自然延长，不以固定宽度截断。

轴线使用同一个直角交点，按各轴边距计算留白，默认两边等距；轴绑定入口居中置于箭头外侧，输出入口随方向切换到右上或右下角的右侧。`action_binding.js` 的 `pickWorkflowTarget` 共用画布拾取与事件拦截流程，卡片绑定和 XY 绑定分别应用拾取结果。XY 拾取不依赖选中的普通模块，完成或取消后重新打开原绑定面板。

`task_dom.js` 只增补缺少的卡片或模块，并使用保持连接状态的移动方式对齐顺序，现有播放器和事件不重建。无关媒体继续复用，被模式隐藏的音视频暂停，再显示时按原状态恢复。附加记录输入在 XY 内标为 `recordOnly`，输入快照和注入链路排除这些字段，执行记录读取工作流实际值；切到卡片或参数表时，按当前工作流值转为普通绑定输入。

#### Z 分层与长文本轴值

矩阵成员仍是原 `cards/areas`；绑定 Z 后，唯一格子的组合键扩展为 X/Y/Z，输出 ID、历史与参数快照按各任务独立保存。`xy_model.js` 补齐三轴组合、保留移出范围的任务，并区分全部格子和当前可见层。Z 绑定和取值、当前层、单层/平铺显示随工作区 `view` 持久化。

`xy_values.js` 只处理轴取值，Z 设置不提供启用开关、间距或边距。Z 绑定摘要左侧的等高方形按钮直接切换单层/平铺，点亮表示平铺，切换时保留按钮 DOM 与键盘焦点。`xy_options.js` 负责完整切层列表和运行按钮右侧的菜单；主按钮默认运行当前层，局部选择优先，“运行全部层”为一次性命令，不持久化运行范围。图层标题按坐标方向分别对齐 Y 轴或 Z 轴绑定摘要，保持在媒体网格上方。

`xy_z_axis.js` 只负责交点左上方的短轴、绑定入口和分层刻度，沿用独立投影层，文本不随媒体纹理一起放大。`xy_layers.js` 计算平铺位置和运行范围，`mode_xy.js` 定位各层原卡片及坐标轴；切换层仅更新可见性、标题和选择状态，复用原媒体 DOM，并暂停隐藏层的音视频。所有层的已加载媒体共同决定占位框比例，避免切层时格子尺寸反复变化。Z 刻度不占用滚轮寻道或画布缩放。

`axis_labels.js` 直接生成实际内容与完整文本提示，长内容由刻度宽度和 CSS 省略处理，不设置显示名称或取值编号。`xy_values.js` 为文本和数字提供统一批量输入框；`value_parser.js` 的轴取值解析按文本换行、数字逗号和换行分别拆分，并支持 JSON 数组及类型化组合。含内部换行、空字符串等不能直接逐行还原的已有值以 JSON 显示，保持原值；参数表继续使用原导入规则。失焦应用时保留当前输入框，避免重建导致焦点或点击丢失。Z 刻度只切层，参数绑定与拾取仍复用原绑定流程。

`axis_value_order.js` 管理“设置取值 / 取值排序”两页，保留输入框及完整勾选列表 DOM。输入时只解析草稿并更新数量，不创建任务；切换排序前复用 `xy_values.js` 的验证与应用，错误草稿不会进入排序。排序把手通过指针捕获显示插入线，仅在松开时写回；边缘滚动帧只在拖动过程中存在。`value_parser.js` 按接缝位置移动完整取值，并保留可往返解析的输入格式。排序提交不重置画布视角，既有组合通过原任务 ID 和参数值重新定位，复用媒体与历史；Z 当前层按原值重新定位索引。

`xy_canvas.js` 只修改平移与缩放变换，固定宽高按比例显示，不用屏幕像素改写生成参数。底部胶囊工具栏切换 Y 向上或向下，方向与视角写入工作区配置；恢复视角按实际工具栏高度预留底部空间。工具栏独立于画布变换，其鼠标与键盘操作不进入抓手或缩放链路。参数摘要展开可搜索的双栏面板，选项仅在打开时创建。模块保存和局部输出刷新通过通知合并到下一帧同步布局，不建立持续轮询。

`xy_axis_panel.js` 按需创建三轴参数选择，`xy_records.js` 通过工具栏独立记录图标管理附加记录的绑定、增减与向上弹出面板，两者分别按需创建和销毁。`xy_axis_swap.js` 只互换两轴的绑定与完整取值，不修改任务参数或媒体。几何间距仍属于原轴；涉及 Z 时由控制器按原可见任务选择新层，再复用原矩阵布局及保存链路。轴向通过工具栏双按钮胶囊直接切换，当前方向使用 `aria-pressed` 标记，切换后恢复按钮焦点；`xy_options.js` 负责运行与层列表菜单。`xy_toolbar_styles.js` 单独保存工具栏和参数面板样式，运行按钮左侧不再放分隔线，默认标签统一为运行和数量。附加记录的绑定与拾取以独立记录按钮作为稳定锚点。

`actions/task_records.js` 单独处理附加运行记录：入队时冻结记录定义和工作流值，在参数注入后以实际提示词参数解析已有值，结果保存到 `historyRuns[].recordParameters`。记录不进入输入注入列表或历史输入恢复，保持执行队列、输出关联和既有参数快照的边界。
