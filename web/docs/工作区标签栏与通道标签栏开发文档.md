# 工作区标签栏与旧通道迁移

本文对应 v1.0.2、schema v4。文件名保留旧通道字样以兼容已有文档链接；当前界面只有工作区标签栏，不再提供独立通道栏。

## 当前界面

- 标签栏默认位于工具栏下方，也可在标签栏空白处右键选择「在上方／在下方」。
- 当前活动标签显示名称及模式按钮，非活动标签悬停显示下三角。模式按钮遵循参数表与 XY 不互转的结构限制。
- 新建工作区使用「模式·工作区 编号」默认名；双击改名后保留自定义名称。
- 支持新建、复制、删除、拖拽重排以及 Ctrl/Cmd 加选、Shift 连选。
- 预览界面复用标签栏行为，并可通过多选标签加入其他预览来源；不会将工作区任务合并。
- 彩虹高亮由 `workspace_tab_highlight.js` 按实际标签位置测量，首次显示、缩放和重开时重新定位。

## schema v4

```js
state = {
  schemaVersion: 4,
  activeWorkspaceId,
  workspaces: [{
    id, name, autoName,
    cards, archivedTasks,
    view, // cards / table / xy、结构类型、轴与表格设置、预览配置
    activeCardId, selectedCardIds, selectedAreaIds,
    painterMode, painterSource, scrollLeft
  }],
  cards, // 当前活动工作区的运行态镜像
  activeCardId, selectedCardIds, selectedAreaIds
}
```

模块直接保存 `targetNodeId`、`targetWidget`、多节点／多参数绑定及显示设置，不再将当前绑定存到活动通道。

## 切换与保存

1. 切换前通过 `syncStateToActiveWorkspace()` 保存当前任务、选择等运行态。
2. `applyWorkspaceToState()` 将目标工作区映射到 `state.cards` 等字段。
3. 工作区控制器按目标模式局部核对 DOM，恢复相应视图；不在切换过程中替换其他工作区的任务对象。
4. 保存时按工作区记录变化并编码，写回配置节点；保存工作流前补存待处理修改。

执行任务引用发起工作区，回传不依赖活动标签。复制工作区保留已完成历史，但清除副本继承的提交标记和仅由未完成运行产生的空归档；原任务的后续结果不会写入副本。

## 旧通道迁移

读取旧配置时，一个通道转换为一个独立工作区，带入该通道绑定及对应任务、参数和历史。只有一个通道时保留原工作区名，多通道副本生成各自名称与稳定 ID。

这是载入迁移，不是继续在 v4 内维护两层标签。新增代码不应调用已移除的通道栏、`applyChannelToState()` 或依赖 `channels[]` 作为当前持久化主体。

## 预览与撤销

预览标签的普通单击切换活动来源，多选增加查看来源；兼容情况下保持当前预览模式，结构冲突时使用目标默认落点。参数表、XY 混合来源不能进入两种专属页面，但可以浏览、比较或制作明细表。

每个工作区有独立内容历史，同一工作区的工作区／预览界面共用记录。标签切换和查看选择不成为内容撤销步骤；撤销到边界不继续使用 ComfyUI 的工作流撤销。
